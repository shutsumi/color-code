藍色のカラーコード

#165E83

植物のアイからとれる染料で染めた色。日本では古くから庶民の着物にも使われてきた青です。

藍色（あいいろ）のカラーコード（色番号・カラーナンバー）は #165E83（「#」シャープつきの6桁の番号）です。RGBでは赤22・緑94・青131。藍色は、暗めで落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

藍色を使うときの目安

白い文字7.1:1
黒い文字3.0:1

藍色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #165E83;            /* 文字を藍色にする */
background-color: #165E83; /* 背景を藍色にする */
