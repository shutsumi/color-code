藍鼠のカラーコード

#5E7C85

藍鼠（あいねず）のカラーコード（色番号・カラーナンバー）は #5E7C85（「#」シャープつきの6桁の番号）です。RGBでは赤94・緑124・青133。藍鼠は、中くらいの明るさでくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

藍鼠を使うときの目安

白い文字4.5:1
黒い文字4.7:1

藍鼠の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 4.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #5E7C85;            /* 文字を藍鼠にする */
background-color: #5E7C85; /* 背景を藍鼠にする */
