赤橙のカラーコード

#F15A22

赤と橙のあいだの色。二つの色名を合わせた、見たままの名前です。

赤橙（あかだいだい）のカラーコード（色番号・カラーナンバー）は #F15A22（「#」シャープつきの6桁の番号）です。RGBでは赤241・緑90・青34。赤橙は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

赤橙を使うときの目安

白い文字3.4:1
黒い文字6.2:1

赤橙の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F15A22;            /* 文字を赤橙にする */
background-color: #F15A22; /* 背景を赤橙にする */
