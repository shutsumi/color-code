赤香色のカラーコード

#F6B894

丁子などの香木で染めた「香色」を赤く寄せた色。僧侶の衣にも使われました。

赤香色（あかこういろ）のカラーコード（色番号・カラーナンバー）は #F6B894（「#」シャープつきの6桁の番号）です。RGBでは赤246・緑184・青148。赤香色は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

赤香色を使うときの目安

白い文字1.7:1
黒い文字12.2:1

赤香色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F6B894;            /* 文字を赤香色にする */
background-color: #F6B894; /* 背景を赤香色にする */
