赤朽葉のカラーコード

#DB8449

秋が深まり、赤く色づいて落ちた葉の色。平安貴族が季節を着こなした色名の一つです。

赤朽葉（あかくちば）のカラーコード（色番号・カラーナンバー）は #DB8449（「#」シャープつきの6桁の番号）です。RGBでは赤219・緑132・青73。赤朽葉は、中くらいの明るさではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

赤朽葉を使うときの目安

白い文字2.8:1
黒い文字7.4:1

赤朽葉の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #DB8449;            /* 文字を赤朽葉にする */
background-color: #DB8449; /* 背景を赤朽葉にする */
