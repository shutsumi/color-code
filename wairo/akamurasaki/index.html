あかむらさき

赤紫のカラーコード

#EB6EA5

赤と紫のあいだの色。つつじや牡丹の花のような、華やかな紫がかった紅です。

赤紫（あかむらさき）のカラーコード（色番号・カラーナンバー）は #EB6EA5（「#」シャープつきの6桁の番号）です。RGBでは赤235・緑110・青165。赤紫は、中くらいの明るさではっきりしたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

赤紫を使うときの目安

白い文字2.9:1
黒い文字7.3:1

赤紫の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #EB6EA5;            /* 文字を赤紫にする */
background-color: #EB6EA5; /* 背景を赤紫にする */
