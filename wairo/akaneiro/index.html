あかねいろ

茜色のカラーコード

#B13546

アカネという草の根で染めた色。夕焼けの空を「茜空」と呼ぶのもこの色から来ています。

茜色（あかねいろ）のカラーコード（色番号・カラーナンバー）は #B13546（「#」シャープつきの6桁の番号）です。RGBでは赤177・緑53・青70。茜色は、暗めではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

茜色を使うときの目安

白い文字6.1:1
黒い文字3.5:1

茜色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B13546;            /* 文字を茜色にする */
background-color: #B13546; /* 背景を茜色にする */
