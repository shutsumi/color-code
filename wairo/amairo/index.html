亜麻色のカラーコード

#D6C6AF

亜麻色（あまいろ）のカラーコード（色番号・カラーナンバー）は #D6C6AF（「#」シャープつきの6桁の番号）です。RGBでは赤214・緑198・青175。亜麻色は、明るくくすんだ橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

亜麻色を使うときの目安

白い文字1.7:1
黒い文字12.6:1

亜麻色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #D6C6AF;            /* 文字を亜麻色にする */
background-color: #D6C6AF; /* 背景を亜麻色にする */
