あめいろ

飴色のカラーコード

#CD6118

昔ながらの水飴の色。使い込んだ革や木が深みを増した様子も「飴色になる」と言います。

飴色（あめいろ）のカラーコード（色番号・カラーナンバー）は #CD6118（「#」シャープつきの6桁の番号）です。RGBでは赤205・緑97・青24。飴色は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

飴色を使うときの目安

白い文字3.9:1
黒い文字5.3:1

飴色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #CD6118;            /* 文字を飴色にする */
background-color: #CD6118; /* 背景を飴色にする */

飴色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
