あんずいろ

杏色のカラーコード

#F4A466

よく熟したアンズの実の色。やわらかな橙です。

杏色（あんずいろ）のカラーコード（色番号・カラーナンバー）は #F4A466（「#」シャープつきの6桁の番号）です。RGBでは赤244・緑164・青102。杏色は、明るくはっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

杏色を使うときの目安

白い文字2.0:1
黒い文字10.3:1

杏色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F4A466;            /* 文字を杏色にする */
background-color: #F4A466; /* 背景を杏色にする */
