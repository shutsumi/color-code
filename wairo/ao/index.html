あお

青のカラーコード

#0067C0

日本語の基本の色名の一つ。古くは緑も含めて「あお」と呼び、青信号や青葉にその名残があります。

青（あお）のカラーコード（色番号・カラーナンバー）は #0067C0（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑103・青192。青は、暗めではっきりした青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青を使うときの目安

白い文字5.7:1
黒い文字3.7:1

青の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #0067C0;            /* 文字を青にする */
background-color: #0067C0; /* 背景を青にする */
