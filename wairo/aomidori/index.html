あおみどり

青緑のカラーコード

#0090A8

青と緑のあいだの色。二つの色名を合わせて、そのまま名前になりました。

青緑（あおみどり）のカラーコード（色番号・カラーナンバー）は #0090A8（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑144・青168。青緑は、中くらいの明るさで落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青緑を使うときの目安

白い文字3.8:1
黒い文字5.6:1

青緑の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #0090A8;            /* 文字を青緑にする */
background-color: #0090A8; /* 背景を青緑にする */
