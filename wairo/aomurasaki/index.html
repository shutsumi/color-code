青紫のカラーコード

#6F51A1

青と紫のあいだの色。紫のなかでも青に寄った側を指します。

青紫（あおむらさき）のカラーコード（色番号・カラーナンバー）は #6F51A1（「#」シャープつきの6桁の番号）です。RGBでは赤111・緑81・青161。青紫は、暗めではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青紫を使うときの目安

白い文字6.2:1
黒い文字3.4:1

青紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6F51A1;            /* 文字を青紫にする */
background-color: #6F51A1; /* 背景を青紫にする */
