青丹のカラーコード

#858954

青丹（あおに）のカラーコード（色番号・カラーナンバー）は #858954（「#」シャープつきの6桁の番号）です。RGBでは赤133・緑137・青84。青丹は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青丹を使うときの目安

白い文字3.7:1
黒い文字5.7:1

青丹の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #858954;            /* 文字を青丹にする */
background-color: #858954; /* 背景を青丹にする */
