青鈍色のカラーコード

#324356

青鈍色（あおにびいろ）のカラーコード（色番号・カラーナンバー）は #324356（「#」シャープつきの6桁の番号）です。RGBでは赤50・緑67・青86。青鈍色は、とても暗くくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青鈍色を使うときの目安

白い文字10.1:1
黒い文字2.1:1

青鈍色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 10.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #324356;            /* 文字を青鈍色にする */
background-color: #324356; /* 背景を青鈍色にする */
