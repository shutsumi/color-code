あおたけいろ

青竹色のカラーコード

#72BAA7

伐ったばかりの青々とした竹の幹から。すっきりとした明るい緑です。

青竹色（あおたけいろ）のカラーコード（色番号・カラーナンバー）は #72BAA7（「#」シャープつきの6桁の番号）です。RGBでは赤114・緑186・青167。青竹色は、明るく落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青竹色を使うときの目安

白い文字2.3:1
黒い文字9.3:1

青竹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #72BAA7;            /* 文字を青竹色にする */
background-color: #72BAA7; /* 背景を青竹色にする */

青竹色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
