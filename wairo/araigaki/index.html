あらいがき

洗柿のカラーコード

#F0B694

柿色を洗いざらして色が落ちたような、淡い橙。「洗」は色あせた様子を表します。

洗柿（あらいがき）のカラーコード（色番号・カラーナンバー）は #F0B694（「#」シャープつきの6桁の番号）です。RGBでは赤240・緑182・青148。洗柿は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

洗柿を使うときの目安

白い文字1.8:1
黒い文字11.8:1

洗柿の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F0B694;            /* 文字を洗柿にする */
background-color: #F0B694; /* 背景を洗柿にする */
