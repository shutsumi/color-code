浅緋のカラーコード

#DF7163

茜で薄く染めた緋色。「浅」は色が薄いことを表し、古代の役人の位を示す服の色でもありました。

浅緋（あさあけ）のカラーコード（色番号・カラーナンバー）は #DF7163（「#」シャープつきの6桁の番号）です。RGBでは赤223・緑113・青99。浅緋は、中くらいの明るさではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

浅緋を使うときの目安

白い文字3.1:1
黒い文字6.7:1

浅緋の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #DF7163;            /* 文字を浅緋にする */
background-color: #DF7163; /* 背景を浅緋にする */
