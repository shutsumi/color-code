浅葱色のカラーコード

#00A4AC

ネギの若葉の色を薄くしたような青緑。新選組の羽織の色として知られています。

浅葱色（あさぎいろ）のカラーコード（色番号・カラーナンバー）は #00A4AC（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑164・青172。浅葱色は、中くらいの明るさではっきりした青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

浅葱色を使うときの目安

白い文字3.0:1
黒い文字6.9:1

浅葱色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #00A4AC;            /* 文字を浅葱色にする */
background-color: #00A4AC; /* 背景を浅葱色にする */

浅葱色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
