浅黄色のカラーコード

#FFCC33

「浅い黄」、つまり薄い黄色のこと。読みが同じ「浅葱色」とよく混同されます。

浅黄色（あさぎいろ）のカラーコード（色番号・カラーナンバー）は #FFCC33（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑204・青51。浅黄色は、明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

浅黄色を使うときの目安

白い文字1.5:1
黒い文字13.9:1

浅黄色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 13.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFCC33;            /* 文字を浅黄色にする */
background-color: #FFCC33; /* 背景を浅黄色にする */
