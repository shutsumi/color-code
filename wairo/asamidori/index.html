あさみどり

浅緑のカラーコード

#9BCF97

芽吹いたばかりの若葉のような、薄い緑。「浅」は色の薄さを表します。

浅緑（あさみどり）のカラーコード（色番号・カラーナンバー）は #9BCF97（「#」シャープつきの6桁の番号）です。RGBでは赤155・緑207・青151。浅緑は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

浅緑を使うときの目安

白い文字1.8:1
黒い文字11.8:1

浅緑の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #9BCF97;            /* 文字を浅緑にする */
background-color: #9BCF97; /* 背景を浅緑にする */

浅緑の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
