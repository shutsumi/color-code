菖蒲色のカラーコード

#B168A8

初夏に咲く花菖蒲（あやめ）の花の色。赤みを帯びた紫です。

菖蒲色（あやめいろ）のカラーコード（色番号・カラーナンバー）は #B168A8（「#」シャープつきの6桁の番号）です。RGBでは赤177・緑104・青168。菖蒲色は、中くらいの明るさではっきりしたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

菖蒲色を使うときの目安

白い文字3.9:1
黒い文字5.4:1

菖蒲色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B168A8;            /* 文字を菖蒲色にする */
background-color: #B168A8; /* 背景を菖蒲色にする */
