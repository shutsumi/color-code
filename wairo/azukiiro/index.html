小豆色のカラーコード

#98514B

和菓子に欠かせない小豆の色。紫がかった落ち着いた赤茶です。

小豆色（あずきいろ）のカラーコード（色番号・カラーナンバー）は #98514B（「#」シャープつきの6桁の番号）です。RGBでは赤152・緑81・青75。小豆色は、暗めで落ち着いた赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

小豆色を使うときの目安

白い文字5.8:1
黒い文字3.6:1

小豆色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #98514B;            /* 文字を小豆色にする */
background-color: #98514B; /* 背景を小豆色にする */
