薔薇色のカラーコード

#E73275

バラの花の色。「バラ色の人生」のように、幸せで明るいもののたとえにも使われます。

薔薇色（ばらいろ）のカラーコード（色番号・カラーナンバー）は #E73275（「#」シャープつきの6桁の番号）です。RGBでは赤231・緑50・青117。薔薇色は、中くらいの明るさで鮮やかなピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

薔薇色を使うときの目安

白い文字4.1:1
黒い文字5.1:1

薔薇色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E73275;            /* 文字を薔薇色にする */
background-color: #E73275; /* 背景を薔薇色にする */

薔薇色の薄い色・濃い色
