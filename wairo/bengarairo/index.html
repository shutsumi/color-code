弁柄色のカラーコード

#8F2E14

インドのベンガル地方から伝わった赤い顔料「ベンガラ」の色。古い町家の壁や格子にも使われます。

弁柄色（べんがらいろ）のカラーコード（色番号・カラーナンバー）は #8F2E14（「#」シャープつきの6桁の番号）です。RGBでは赤143・緑46・青20。弁柄色は、暗めではっきりした茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

弁柄色を使うときの目安

白い文字8.2:1
黒い文字2.6:1

弁柄色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 8.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #8F2E14;            /* 文字を弁柄色にする */
background-color: #8F2E14; /* 背景を弁柄色にする */

弁柄色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
