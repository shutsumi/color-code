紅緋のカラーコード

#F83929

紅花の紅と、ウコンなどの黄色を染め重ねた、冴えた黄みの赤です。

紅緋（べにひ）のカラーコード（色番号・カラーナンバー）は #F83929（「#」シャープつきの6桁の番号）です。RGBでは赤248・緑57・青41。紅緋は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紅緋を使うときの目安

白い文字3.7:1
黒い文字5.6:1

紅緋の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F83929;            /* 文字を紅緋にする */
background-color: #F83929; /* 背景を紅緋にする */
