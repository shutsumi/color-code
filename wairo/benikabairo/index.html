べにかばいろ

紅樺色のカラーコード

#B63D1B

紅色がかった樺色。赤みの強い橙茶です。

紅樺色（べにかばいろ）のカラーコード（色番号・カラーナンバー）は #B63D1B（「#」シャープつきの6桁の番号）です。RGBでは赤182・緑61・青27。紅樺色は、暗めで鮮やかな茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紅樺色を使うときの目安

白い文字5.7:1
黒い文字3.7:1

紅樺色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B63D1B;            /* 文字を紅樺色にする */
background-color: #B63D1B; /* 背景を紅樺色にする */
