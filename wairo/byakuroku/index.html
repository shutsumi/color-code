白緑のカラーコード

#DAEAD0

岩絵具の緑青を細かく砕いてできる、白みを帯びた淡い緑です。

白緑（びゃくろく）のカラーコード（色番号・カラーナンバー）は #DAEAD0（「#」シャープつきの6桁の番号）です。RGBでは赤218・緑234・青208。白緑は、とても明るくくすんだ緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

白緑を使うときの目安

白い文字1.3:1
黒い文字16.7:1

白緑の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 16.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #DAEAD0;            /* 文字を白緑にする */
background-color: #DAEAD0; /* 背景を白緑にする */

白緑の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
