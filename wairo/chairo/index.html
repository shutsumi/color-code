茶色のカラーコード

#994C00

茶色（ちゃいろ）のカラーコード（色番号・カラーナンバー）は #994C00（「#」シャープつきの6桁の番号）です。RGBでは赤153・緑76・青0。茶色は、暗めではっきりした茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

茶色を使うときの目安

白い文字6.2:1
黒い文字3.4:1

茶色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #994C00;            /* 文字を茶色にする */
background-color: #994C00; /* 背景を茶色にする */
