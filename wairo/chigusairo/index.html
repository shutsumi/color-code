千草色のカラーコード

#92B5A9

薄い藍に、さらに薄く藍を重ねた淡い青。わずかに緑みを帯びています。

千草色（ちぐさいろ）のカラーコード（色番号・カラーナンバー）は #92B5A9（「#」シャープつきの6桁の番号）です。RGBでは赤146・緑181・青169。千草色は、明るくくすんだ緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

千草色を使うときの目安

白い文字2.2:1
黒い文字9.4:1

千草色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #92B5A9;            /* 文字を千草色にする */
background-color: #92B5A9; /* 背景を千草色にする */
