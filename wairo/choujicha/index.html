丁子茶のカラーコード

#B4866B

丁子茶（ちょうじちゃ）のカラーコード（色番号・カラーナンバー）は #B4866B（「#」シャープつきの6桁の番号）です。RGBでは赤180・緑134・青107。丁子茶は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

丁子茶を使うときの目安

白い文字3.2:1
黒い文字6.6:1

丁子茶の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B4866B;            /* 文字を丁子茶にする */
background-color: #B4866B; /* 背景を丁子茶にする */
