橙色のカラーコード

#FFB74C

果物のダイダイの実の色。実が年を越しても落ちないことから「代々」と縁起をかつがれます。

橙色（だいだいいろ）のカラーコード（色番号・カラーナンバー）は #FFB74C（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑183・青76。橙色は、明るく鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

橙色を使うときの目安

白い文字1.7:1
黒い文字12.1:1

橙色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFB74C;            /* 文字を橙色にする */
background-color: #FFB74C; /* 背景を橙色にする */
