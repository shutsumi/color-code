団十郎茶のカラーコード

#9F563A

歌舞伎の市川團十郎家が代々使ってきた柿色。十八番『暫』の衣装の色として知られます。

団十郎茶（だんじゅうろうちゃ）のカラーコード（色番号・カラーナンバー）は #9F563A（「#」シャープつきの6桁の番号）です。RGBでは赤159・緑86・青58。団十郎茶は、暗めではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

団十郎茶を使うときの目安

白い文字5.4:1
黒い文字3.9:1

団十郎茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #9F563A;            /* 文字を団十郎茶にする */
background-color: #9F563A; /* 背景を団十郎茶にする */
