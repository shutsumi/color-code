葡萄茶のカラーコード

#6C2C2F

山ぶどうの色を茶色寄りにした色。明治の女学生の袴の色で「海老茶式部」と呼ばれました。

葡萄茶（えびちゃ）のカラーコード（色番号・カラーナンバー）は #6C2C2F（「#」シャープつきの6桁の番号）です。RGBでは赤108・緑44・青47。葡萄茶は、とても暗く落ち着いた赤系の色です。

別の書き方：海老茶

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

葡萄茶を使うときの目安

白い文字10.3:1
黒い文字2.0:1

葡萄茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 10.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6C2C2F;            /* 文字を葡萄茶にする */
background-color: #6C2C2F; /* 背景を葡萄茶にする */

葡萄茶の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
