葡萄色のカラーコード

#640125

山ぶどう（葡萄葛）の古名「えび」から。のちに海老と混同され「海老色」とも書かれます。

葡萄色（えびいろ）のカラーコード（色番号・カラーナンバー）は #640125（「#」シャープつきの6桁の番号）です。RGBでは赤100・緑1・青37。葡萄色は、とても暗くはっきりした赤系の色です。

別の書き方：海老色

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

葡萄色を使うときの目安

白い文字13.4:1
黒い文字1.6:1

葡萄色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 13.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #640125;            /* 文字を葡萄色にする */
background-color: #640125; /* 背景を葡萄色にする */

葡萄色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
