葡萄染のカラーコード

#7A4171

山ぶどう（葡萄葛）の熟した実の色に染めること。平安時代の装束の色名です。

葡萄染（えびぞめ）のカラーコード（色番号・カラーナンバー）は #7A4171（「#」シャープつきの6桁の番号）です。RGBでは赤122・緑65・青113。葡萄染は、暗めではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

葡萄染を使うときの目安

白い文字7.4:1
黒い文字2.8:1

葡萄染の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7A4171;            /* 文字を葡萄染にする */
background-color: #7A4171; /* 背景を葡萄染にする */
