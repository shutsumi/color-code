江戸茶のカラーコード

#CD8C5C

江戸時代の初めに流行した茶色。流行色に「江戸」の名が付けられました。

江戸茶（えどちゃ）のカラーコード（色番号・カラーナンバー）は #CD8C5C（「#」シャープつきの6桁の番号）です。RGBでは赤205・緑140・青92。江戸茶は、中くらいの明るさではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

江戸茶を使うときの目安

白い文字2.8:1
黒い文字7.5:1

江戸茶の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #CD8C5C;            /* 文字を江戸茶にする */
background-color: #CD8C5C; /* 背景を江戸茶にする */
