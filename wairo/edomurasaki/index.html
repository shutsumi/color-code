江戸紫のカラーコード

#745399

江戸で染められた紫。歌舞伎『助六』の鉢巻の色として知られ、京紫と並び称されます。

江戸紫（えどむらさき）のカラーコード（色番号・カラーナンバー）は #745399（「#」シャープつきの6桁の番号）です。RGBでは赤116・緑83・青153。江戸紫は、暗めではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

江戸紫を使うときの目安

白い文字6.1:1
黒い文字3.4:1

江戸紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #745399;            /* 文字を江戸紫にする */
background-color: #745399; /* 背景を江戸紫にする */
