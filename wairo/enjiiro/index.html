臙脂色のカラーコード

#B3424A

カイガラムシや紅花からとった赤い顔料「臙脂」の色。深く黒みのある赤です。

臙脂色（えんじいろ）のカラーコード（色番号・カラーナンバー）は #B3424A（「#」シャープつきの6桁の番号）です。RGBでは赤179・緑66・青74。臙脂色は、暗めではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

臙脂色を使うときの目安

白い文字5.5:1
黒い文字3.8:1

臙脂色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B3424A;            /* 文字を臙脂色にする */
background-color: #B3424A; /* 背景を臙脂色にする */
