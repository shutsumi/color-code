鉛丹色のカラーコード

#EC6D51

鉛丹色（えんたんいろ）のカラーコード（色番号・カラーナンバー）は #EC6D51（「#」シャープつきの6桁の番号）です。RGBでは赤236・緑109・青81。鉛丹色は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鉛丹色を使うときの目安

白い文字3.1:1
黒い文字6.9:1

鉛丹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #EC6D51;            /* 文字を鉛丹色にする */
background-color: #EC6D51; /* 背景を鉛丹色にする */
