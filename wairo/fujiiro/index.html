ふじいろ

藤色のカラーコード

#AFB4DB

春の終わりに房になって咲くフジの花の色。淡い青みの紫です。

藤色（ふじいろ）のカラーコード（色番号・カラーナンバー）は #AFB4DB（「#」シャープつきの6桁の番号）です。RGBでは赤175・緑180・青219。藤色は、明るく落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

藤色を使うときの目安

白い文字2.0:1
黒い文字10.4:1

藤色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AFB4DB;            /* 文字を藤色にする */
background-color: #AFB4DB; /* 背景を藤色にする */

藤色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
