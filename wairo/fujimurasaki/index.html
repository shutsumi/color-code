藤紫のカラーコード

#9B95C9

藤の花のような、明るい青紫です。

藤紫（ふじむらさき）のカラーコード（色番号・カラーナンバー）は #9B95C9（「#」シャープつきの6桁の番号）です。RGBでは赤155・緑149・青201。藤紫は、中くらいの明るさで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

藤紫を使うときの目安

白い文字2.8:1
黒い文字7.5:1

藤紫の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #9B95C9;            /* 文字を藤紫にする */
background-color: #9B95C9; /* 背景を藤紫にする */

藤紫の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
