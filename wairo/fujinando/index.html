藤納戸のカラーコード

#606DA1

藤納戸（ふじなんど）のカラーコード（色番号・カラーナンバー）は #606DA1（「#」シャープつきの6桁の番号）です。RGBでは赤96・緑109・青161。藤納戸は、中くらいの明るさで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

藤納戸を使うときの目安

白い文字5.0:1
黒い文字4.2:1

藤納戸の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #606DA1;            /* 文字を藤納戸にする */
background-color: #606DA1; /* 背景を藤納戸にする */
