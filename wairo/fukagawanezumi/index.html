ふかがわねずみ

深川鼠のカラーコード

#85A1A0

江戸・深川の名が付いた鼠色。うっすら青緑を帯びた、粋な灰色です。

深川鼠（ふかがわねずみ）のカラーコード（色番号・カラーナンバー）は #85A1A0（「#」シャープつきの6桁の番号）です。RGBでは赤133・緑161・青160。深川鼠は、中くらいの明るさでくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

深川鼠を使うときの目安

白い文字2.8:1
黒い文字7.6:1

深川鼠の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #85A1A0;            /* 文字を深川鼠にする */
background-color: #85A1A0; /* 背景を深川鼠にする */

深川鼠の薄い色・濃い色
