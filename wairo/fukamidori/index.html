深緑のカラーコード

#004025

深緑（ふかみどり）のカラーコード（色番号・カラーナンバー）は #004025（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑64・青37。深緑は、とても暗く落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

深緑を使うときの目安

白い文字11.9:1
黒い文字1.8:1

深緑の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 11.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #004025;            /* 文字を深緑にする */
background-color: #004025; /* 背景を深緑にする */
