二藍のカラーコード

#6B4978

二藍（ふたあい）のカラーコード（色番号・カラーナンバー）は #6B4978（「#」シャープつきの6桁の番号）です。RGBでは赤107・緑73・青120。二藍は、暗めで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

二藍を使うときの目安

白い文字7.4:1
黒い文字2.8:1

二藍の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6B4978;            /* 文字を二藍にする */
background-color: #6B4978; /* 背景を二藍にする */
