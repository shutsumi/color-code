月白のカラーコード

#F6F7F8

月の光を思わせる、ほんのり青みを帯びた白。月がのぼる前に空が白むさまとも言われます。

月白（げっぱく）のカラーコード（色番号・カラーナンバー）は #F6F7F8（「#」シャープつきの6桁の番号）です。RGBでは赤246・緑247・青248。月白は、白に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

月白を使うときの目安

白い文字1.1:1
黒い文字19.6:1

月白の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 19.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F6F7F8;            /* 文字を月白にする */
background-color: #F6F7F8; /* 背景を月白にする */
