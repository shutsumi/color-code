ぎんいろ

銀色のカラーコード

#C0C0C0

金属の銀の色。「白銀（しろがね）」とも呼ばれます。

銀色（ぎんいろ）のカラーコード（色番号・カラーナンバー）は #C0C0C0（「#」シャープつきの6桁の番号）です。RGBでは赤192・緑192・青192。銀色は、明るい灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

銀色を使うときの目安

白い文字1.8:1
黒い文字11.5:1

銀色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C0C0C0;            /* 文字を銀色にする */
background-color: #C0C0C0; /* 背景を銀色にする */

銀色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
