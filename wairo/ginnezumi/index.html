ぎんねずみ

銀鼠のカラーコード

#BBBCBF

銀のように明るく、ほんのり青みのある鼠色。江戸時代の粋な色の一つです。

銀鼠（ぎんねずみ）のカラーコード（色番号・カラーナンバー）は #BBBCBF（「#」シャープつきの6桁の番号）です。RGBでは赤187・緑188・青191。銀鼠は、明るい灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

銀鼠を使うときの目安

白い文字1.9:1
黒い文字11.1:1

銀鼠の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #BBBCBF;            /* 文字を銀鼠にする */
background-color: #BBBCBF; /* 背景を銀鼠にする */
