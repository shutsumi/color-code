銀朱のカラーコード

#F12B00

銀朱（ぎんしゅ）のカラーコード（色番号・カラーナンバー）は #F12B00（「#」シャープつきの6桁の番号）です。RGBでは赤241・緑43・青0。銀朱は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

銀朱を使うときの目安

白い文字4.1:1
黒い文字5.1:1

銀朱の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F12B00;            /* 文字を銀朱にする */
background-color: #F12B00; /* 背景を銀朱にする */
