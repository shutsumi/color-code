群青色のカラーコード

#465DAA

群青色（ぐんじょういろ）のカラーコード（色番号・カラーナンバー）は #465DAA（「#」シャープつきの6桁の番号）です。RGBでは赤70・緑93・青170。群青色は、暗めではっきりした青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

群青色を使うときの目安

白い文字6.2:1
黒い文字3.4:1

群青色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #465DAA;            /* 文字を群青色にする */
background-color: #465DAA; /* 背景を群青色にする */
