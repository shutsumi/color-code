紅蓮色のカラーコード

#AD002D

紅蓮色（ぐれんいろ）のカラーコード（色番号・カラーナンバー）は #AD002D（「#」シャープつきの6桁の番号）です。RGBでは赤173・緑0・青45。紅蓮色は、暗めで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紅蓮色を使うときの目安

白い文字7.5:1
黒い文字2.8:1

紅蓮色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AD002D;            /* 文字を紅蓮色にする */
background-color: #AD002D; /* 背景を紅蓮色にする */
