肌色のカラーコード

#F1BB93

肌の色に似せた薄い橙。いまは人によって肌の色が違うことから「薄橙」と呼ぶことが増えています。

肌色（はだいろ）のカラーコード（色番号・カラーナンバー）は #F1BB93（「#」シャープつきの6桁の番号）です。RGBでは赤241・緑187・青147。肌色は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

肌色を使うときの目安

白い文字1.7:1
黒い文字12.3:1

肌色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F1BB93;            /* 文字を肌色にする */
background-color: #F1BB93; /* 背景を肌色にする */
