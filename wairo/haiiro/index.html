はいいろ

灰色のカラーコード

#808080

物が燃えたあとに残る灰の色。白と黒のあいだの色です。

灰色（はいいろ）のカラーコード（色番号・カラーナンバー）は #808080（「#」シャープつきの6桁の番号）です。RGBでは赤128・緑128・青128。灰色は、灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

灰色を使うときの目安

白い文字3.9:1
黒い文字5.3:1

灰色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #808080;            /* 文字を灰色にする */
background-color: #808080; /* 背景を灰色にする */

灰色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
