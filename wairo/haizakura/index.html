灰桜のカラーコード

#E8D3D1

桜色に灰色を少し混ぜた色。くすんだ、やわらかな紅です。

灰桜（はいざくら）のカラーコード（色番号・カラーナンバー）は #E8D3D1（「#」シャープつきの6桁の番号）です。RGBでは赤232・緑211・青209。灰桜は、とても明るくくすんだピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

灰桜を使うときの目安

白い文字1.4:1
黒い文字14.7:1

灰桜の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 14.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E8D3D1;            /* 文字を灰桜にする */
background-color: #E8D3D1; /* 背景を灰桜にする */

灰桜の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
