縹色のカラーコード

#267CA7

縹色（はなだいろ）のカラーコード（色番号・カラーナンバー）は #267CA7（「#」シャープつきの6桁の番号）です。RGBでは赤38・緑124・青167。縹色は、中くらいの明るさで落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

縹色を使うときの目安

白い文字4.6:1
黒い文字4.5:1

縹色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #267CA7;            /* 文字を縹色にする */
background-color: #267CA7; /* 背景を縹色にする */
