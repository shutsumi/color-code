唐棣色のカラーコード

#F0908D

「唐棣（はねず）」は庭梅の古い名前。庭梅の花のような薄い赤です。

唐棣色（はねずいろ）のカラーコード（色番号・カラーナンバー）は #F0908D（「#」シャープつきの6桁の番号）です。RGBでは赤240・緑144・青141。唐棣色は、明るくはっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

唐棣色を使うときの目安

白い文字2.3:1
黒い文字9.1:1

唐棣色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F0908D;            /* 文字を唐棣色にする */
background-color: #F0908D; /* 背景を唐棣色にする */

唐棣色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
