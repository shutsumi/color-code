榛色のカラーコード

#BFA46F

榛色（はしばみいろ）のカラーコード（色番号・カラーナンバー）は #BFA46F（「#」シャープつきの6桁の番号）です。RGBでは赤191・緑164・青111。榛色は、明るく落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

榛色を使うときの目安

白い文字2.4:1
黒い文字8.8:1

榛色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #BFA46F;            /* 文字を榛色にする */
background-color: #BFA46F; /* 背景を榛色にする */
