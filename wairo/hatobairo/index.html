鳩羽色のカラーコード

#95859C

ハトの羽の色。灰色がかった淡い青紫です。

鳩羽色（はとばいろ）のカラーコード（色番号・カラーナンバー）は #95859C（「#」シャープつきの6桁の番号）です。RGBでは赤149・緑133・青156。鳩羽色は、中くらいの明るさでくすんだ紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鳩羽色を使うときの目安

白い文字3.4:1
黒い文字6.1:1

鳩羽色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #95859C;            /* 文字を鳩羽色にする */
background-color: #95859C; /* 背景を鳩羽色にする */

鳩羽色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
