緋色のカラーコード

#E54848

茜で濃く染めた、あざやかな赤。「緋」は火の色を表す字です。

緋色（ひいろ）のカラーコード（色番号・カラーナンバー）は #E54848（「#」シャープつきの6桁の番号）です。RGBでは赤229・緑72・青72。緋色は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

緋色を使うときの目安

白い文字3.9:1
黒い文字5.4:1

緋色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E54848;            /* 文字を緋色にする */
background-color: #E54848; /* 背景を緋色にする */

緋色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
