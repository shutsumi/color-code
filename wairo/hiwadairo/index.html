桧皮色のカラーコード

#7B4334

桧皮色（ひわだいろ）のカラーコード（色番号・カラーナンバー）は #7B4334（「#」シャープつきの6桁の番号）です。RGBでは赤123・緑67・青52。桧皮色は、暗めで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

桧皮色を使うときの目安

白い文字7.8:1
黒い文字2.7:1

桧皮色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7B4334;            /* 文字を桧皮色にする */
background-color: #7B4334; /* 背景を桧皮色にする */
