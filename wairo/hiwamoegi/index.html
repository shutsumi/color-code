鶸萌黄のカラーコード

#82AE46

小鳥・ヒワの羽のような黄色みと、萌黄色を合わせた色。黄みの強い黄緑です。

鶸萌黄（ひわもえぎ）のカラーコード（色番号・カラーナンバー）は #82AE46（「#」シャープつきの6桁の番号）です。RGBでは赤130・緑174・青70。鶸萌黄は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鶸萌黄を使うときの目安

白い文字2.6:1
黒い文字8.1:1

鶸萌黄の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #82AE46;            /* 文字を鶸萌黄にする */
background-color: #82AE46; /* 背景を鶸萌黄にする */
