いっこんぞめ

一斤染のカラーコード

#FFD3E4

紅花一斤で絹一疋を染めた淡い紅。これより薄い紅なら、身分を問わず着ることが許されていました。

一斤染（いっこんぞめ）のカラーコード（色番号・カラーナンバー）は #FFD3E4（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑211・青228。一斤染は、とても明るく落ち着いたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

一斤染を使うときの目安

白い文字1.3:1
黒い文字15.7:1

一斤染の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 15.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFD3E4;            /* 文字を一斤染にする */
background-color: #FFD3E4; /* 背景を一斤染にする */

一斤染の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
