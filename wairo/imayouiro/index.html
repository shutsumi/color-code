今様色のカラーコード

#D0576B

今様色（いまよういろ）のカラーコード（色番号・カラーナンバー）は #D0576B（「#」シャープつきの6桁の番号）です。RGBでは赤208・緑87・青107。今様色は、中くらいの明るさではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

今様色を使うときの目安

白い文字4.0:1
黒い文字5.3:1

今様色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #D0576B;            /* 文字を今様色にする */
background-color: #D0576B; /* 背景を今様色にする */
