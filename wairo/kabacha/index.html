樺茶のカラーコード

#726250

樺色を帯びた茶色。江戸時代に好まれた茶系の色の一つです。

樺茶（かばちゃ）のカラーコード（色番号・カラーナンバー）は #726250（「#」シャープつきの6桁の番号）です。RGBでは赤114・緑98・青80。樺茶は、暗めでくすんだ茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

樺茶を使うときの目安

白い文字5.9:1
黒い文字3.6:1

樺茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #726250;            /* 文字を樺茶にする */
background-color: #726250; /* 背景を樺茶にする */
