樺色のカラーコード

#C5591A

樺色（かばいろ）のカラーコード（色番号・カラーナンバー）は #C5591A（「#」シャープつきの6桁の番号）です。RGBでは赤197・緑89・青26。樺色は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

別の書き方：蒲色

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

樺色を使うときの目安

白い文字4.4:1
黒い文字4.8:1

樺色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 4.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C5591A;            /* 文字を樺色にする */
background-color: #C5591A; /* 背景を樺色にする */
