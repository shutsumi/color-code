勝色のカラーコード

#4D5269

濃い紺の「褐色（かちいろ）」が「勝ち」に通じることから、鎌倉時代の武士に縁起のよい色として好まれました。

勝色（かちいろ）のカラーコード（色番号・カラーナンバー）は #4D5269（「#」シャープつきの6桁の番号）です。RGBでは赤77・緑82・青105。勝色は、暗めでくすんだ紫系の色です。「かついろ」とも読みます。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

勝色を使うときの目安

白い文字7.7:1
黒い文字2.7:1

勝色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #4D5269;            /* 文字を勝色にする */
background-color: #4D5269; /* 背景を勝色にする */

勝色の薄い色・濃い色
