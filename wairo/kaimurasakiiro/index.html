かいむらさきいろ

貝紫色のカラーコード

#7F1184

地中海などにいる巻貝の分泌液で染めた紫。古代ローマでは皇帝の色とされるほど貴重でした。

貝紫色（かいむらさきいろ）のカラーコード（色番号・カラーナンバー）は #7F1184（「#」シャープつきの6桁の番号）です。RGBでは赤127・緑17・青132。貝紫色は、暗めで鮮やかな紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

貝紫色を使うときの目安

白い文字9.1:1
黒い文字2.3:1

貝紫色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7F1184;            /* 文字を貝紫色にする */
background-color: #7F1184; /* 背景を貝紫色にする */
