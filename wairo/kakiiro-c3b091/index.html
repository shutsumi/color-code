かーきいろ

カーキ色のカラーコード

#C3B091

ペルシャ語・ヒンディー語で「土ぼこり」を意味する言葉から。軍服の色として広まりました。

カーキ色（かーきいろ）のカラーコード（色番号・カラーナンバー）は #C3B091（「#」シャープつきの6桁の番号）です。RGBでは赤195・緑176・青145。カーキ色は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

カーキ色を使うときの目安

白い文字2.1:1
黒い文字9.9:1

カーキ色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C3B091;            /* 文字をカーキ色にする */
background-color: #C3B091; /* 背景をカーキ色にする */

カーキ色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
