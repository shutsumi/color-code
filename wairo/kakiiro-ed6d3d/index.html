柿色のカラーコード

#ED6D3D

柿色（かきいろ）のカラーコード（色番号・カラーナンバー）は #ED6D3D（「#」シャープつきの6桁の番号）です。RGBでは赤237・緑109・青61。柿色は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

柿色を使うときの目安

白い文字3.1:1
黒い文字6.9:1

柿色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #ED6D3D;            /* 文字を柿色にする */
background-color: #ED6D3D; /* 背景を柿色にする */
