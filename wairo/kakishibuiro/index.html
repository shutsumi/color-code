柿渋色のカラーコード

#BD7862

まだ青い柿の実をしぼって発酵させた「柿渋」で染めた色。防水や防腐にも使われてきました。

柿渋色（かきしぶいろ）のカラーコード（色番号・カラーナンバー）は #BD7862（「#」シャープつきの6桁の番号）です。RGBでは赤189・緑120・青98。柿渋色は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

柿渋色を使うときの目安

白い文字3.5:1
黒い文字6.0:1

柿渋色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #BD7862;            /* 文字を柿渋色にする */
background-color: #BD7862; /* 背景を柿渋色にする */
