杜若色のカラーコード

#5E3862

杜若色（かきつばたいろ）のカラーコード（色番号・カラーナンバー）は #5E3862（「#」シャープつきの6桁の番号）です。RGBでは赤94・緑56・青98。杜若色は、暗めで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

杜若色を使うときの目安

白い文字9.5:1
黒い文字2.2:1

杜若色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #5E3862;            /* 文字を杜若色にする */
background-color: #5E3862; /* 背景を杜若色にする */
