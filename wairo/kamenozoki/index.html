瓶覗のカラーコード

#C5E4ED

藍染めで、藍の瓶にほんの少しくぐらせただけの淡い青。「瓶をのぞいた程度」という洒落た名前です。

瓶覗（かめのぞき）のカラーコード（色番号・カラーナンバー）は #C5E4ED（「#」シャープつきの6桁の番号）です。RGBでは赤197・緑228・青237。瓶覗は、とても明るくくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

瓶覗を使うときの目安

白い文字1.3:1
黒い文字15.7:1

瓶覗の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 15.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C5E4ED;            /* 文字を瓶覗にする */
background-color: #C5E4ED; /* 背景を瓶覗にする */
