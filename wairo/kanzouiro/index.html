萱草色のカラーコード

#F8B862

夏に橙色の花を咲かせるカンゾウの色。「忘れ草」とも呼ばれ、喪の色にも使われました。

萱草色（かんぞういろ）のカラーコード（色番号・カラーナンバー）は #F8B862（「#」シャープつきの6桁の番号）です。RGBでは赤248・緑184・青98。萱草色は、明るくはっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

萱草色を使うときの目安

白い文字1.7:1
黒い文字12.0:1

萱草色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F8B862;            /* 文字を萱草色にする */
background-color: #F8B862; /* 背景を萱草色にする */

萱草色の薄い色・濃い色
