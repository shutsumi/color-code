唐茶のカラーコード

#A06705

唐茶（からちゃ）のカラーコード（色番号・カラーナンバー）は #A06705（「#」シャープつきの6桁の番号）です。RGBでは赤160・緑103・青5。唐茶は、中くらいの明るさではっきりした茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

唐茶を使うときの目安

白い文字4.7:1
黒い文字4.4:1

唐茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A06705;            /* 文字を唐茶にする */
background-color: #A06705; /* 背景を唐茶にする */
