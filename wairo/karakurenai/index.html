唐紅のカラーコード

#D93448

大陸から伝わった紅という意味。百人一首の「からくれなゐに水くくるとは」の歌で知られます。

唐紅（からくれない）のカラーコード（色番号・カラーナンバー）は #D93448（「#」シャープつきの6桁の番号）です。RGBでは赤217・緑52・青72。唐紅は、中くらいの明るさで鮮やかな赤系の色です。

別の書き方：韓紅

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

唐紅を使うときの目安

白い文字4.6:1
黒い文字4.5:1

唐紅の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #D93448;            /* 文字を唐紅にする */
background-color: #D93448; /* 背景を唐紅にする */
