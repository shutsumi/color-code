からしいろ

芥子色のカラーコード

#D0AF4C

からしの粉の色。少しくすんだ黄色です。

芥子色（からしいろ）のカラーコード（色番号・カラーナンバー）は #D0AF4C（「#」シャープつきの6桁の番号）です。RGBでは赤208・緑175・青76。芥子色は、明るくはっきりした黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

芥子色を使うときの目安

白い文字2.1:1
黒い文字9.9:1

芥子色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #D0AF4C;            /* 文字を芥子色にする */
background-color: #D0AF4C; /* 背景を芥子色にする */

芥子色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
