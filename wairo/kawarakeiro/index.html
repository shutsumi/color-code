土器色のカラーコード

#C37854

素焼きの土器のような色。くすんだ黄みの茶です。

土器色（かわらけいろ）のカラーコード（色番号・カラーナンバー）は #C37854（「#」シャープつきの6桁の番号）です。RGBでは赤195・緑120・青84。土器色は、中くらいの明るさではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

土器色を使うときの目安

白い文字3.4:1
黒い文字6.1:1

土器色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C37854;            /* 文字を土器色にする */
background-color: #C37854; /* 背景を土器色にする */
