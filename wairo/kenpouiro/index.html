憲法色のカラーコード

#543F32

京の剣術家・吉岡憲法が広めたと伝わる染め色。黒に近い茶色です。

憲法色（けんぽういろ）のカラーコード（色番号・カラーナンバー）は #543F32（「#」シャープつきの6桁の番号）です。RGBでは赤84・緑63・青50。憲法色は、暗めでくすんだ茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

憲法色を使うときの目安

白い文字9.8:1
黒い文字2.1:1

憲法色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #543F32;            /* 文字を憲法色にする */
background-color: #543F32; /* 背景を憲法色にする */
