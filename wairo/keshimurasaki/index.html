滅紫のカラーコード

#594255

紫根で染めた紫が、くすんで色が消えかけたような色。「滅」は色があせた様子を表します。

滅紫（けしむらさき）のカラーコード（色番号・カラーナンバー）は #594255（「#」シャープつきの6桁の番号）です。RGBでは赤89・緑66・青85。滅紫は、暗めでくすんだ紫系の色です。「めっし」とも読みます。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

滅紫を使うときの目安

白い文字9.0:1
黒い文字2.3:1

滅紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #594255;            /* 文字を滅紫にする */
background-color: #594255; /* 背景を滅紫にする */
