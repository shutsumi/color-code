黄蘗色のカラーコード

#FCF16E

ミカンの仲間・キハダの樹皮で染めた黄色。キハダは胃腸の薬としても使われます。

黄蘗色（きはだいろ）のカラーコード（色番号・カラーナンバー）は #FCF16E（「#」シャープつきの6桁の番号）です。RGBでは赤252・緑241・青110。黄蘗色は、とても明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黄蘗色を使うときの目安

白い文字1.2:1
黒い文字17.9:1

黄蘗色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 17.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FCF16E;            /* 文字を黄蘗色にする */
background-color: #FCF16E; /* 背景を黄蘗色にする */

黄蘗色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
