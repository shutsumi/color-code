黄色のカラーコード

#FFD400

黄色（きいろ）のカラーコード（色番号・カラーナンバー）は #FFD400（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑212・青0。黄色は、とても明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黄色を使うときの目安

白い文字1.4:1
黒い文字14.7:1

黄色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 14.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFD400;            /* 文字を黄色にする */
background-color: #FFD400; /* 背景を黄色にする */
