麹塵のカラーコード

#BFBD9E

こうじカビのような色、という意味の名前。天皇がふだん着る袍の色でした。

麹塵（きくじん）のカラーコード（色番号・カラーナンバー）は #BFBD9E（「#」シャープつきの6桁の番号）です。RGBでは赤191・緑189・青158。麹塵は、明るくくすんだ黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

同じカラーコードで載っている色：山鳩色

麹塵を使うときの目安

白い文字1.9:1
黒い文字11.0:1

麹塵の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #BFBD9E;            /* 文字を麹塵にする */
background-color: #BFBD9E; /* 背景を麹塵にする */

麹塵の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
