黄緑色のカラーコード

#B9C42F

黄色と緑のあいだの色。二つの色名を合わせた、見たままの名前です。

黄緑色（きみどりいろ）のカラーコード（色番号・カラーナンバー）は #B9C42F（「#」シャープつきの6桁の番号）です。RGBでは赤185・緑196・青47。黄緑色は、明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黄緑色を使うときの目安

白い文字1.9:1
黒い文字11.0:1

黄緑色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B9C42F;            /* 文字を黄緑色にする */
background-color: #B9C42F; /* 背景を黄緑色にする */
