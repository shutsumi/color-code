きなりいろ

生成色のカラーコード

#C2B280

染めたり漂白したりしていない、糸や布そのままの色。「きなり」は手を加えない状態を表します。

生成色（きなりいろ）のカラーコード（色番号・カラーナンバー）は #C2B280（「#」シャープつきの6桁の番号）です。RGBでは赤194・緑178・青128。生成色は、明るく落ち着いた黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

生成色を使うときの目安

白い文字2.1:1
黒い文字10.0:1

生成色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C2B280;            /* 文字を生成色にする */
background-color: #C2B280; /* 背景を生成色にする */
