金茶のカラーコード

#E0861A

金色に近い、明るい黄みの茶。「山吹茶」とも呼ばれます。

金茶（きんちゃ）のカラーコード（色番号・カラーナンバー）は #E0861A（「#」シャープつきの6桁の番号）です。RGBでは赤224・緑134・青26。金茶は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

金茶を使うときの目安

白い文字2.8:1
黒い文字7.6:1

金茶の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E0861A;            /* 文字を金茶にする */
background-color: #E0861A; /* 背景を金茶にする */
