金色のカラーコード

#FFD700

金属の金の色。「黄金色（こがねいろ）」とも呼ばれ、富や豊かさの象徴です。

金色（きんいろ）のカラーコード（色番号・カラーナンバー）は #FFD700（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑215・青0。金色は、とても明るく鮮やかな黄系の色です。「こんじき」とも読みます。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

金色を使うときの目安

白い文字1.4:1
黒い文字15.0:1

金色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 15.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFD700;            /* 文字を金色にする */
background-color: #FFD700; /* 背景を金色にする */
