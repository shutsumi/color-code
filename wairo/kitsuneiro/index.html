きつねいろ

狐色のカラーコード

#C48847

キツネの毛の色。パンや天ぷらが「こんがりきつね色」に焼ける、あの色です。

狐色（きつねいろ）のカラーコード（色番号・カラーナンバー）は #C48847（「#」シャープつきの6桁の番号）です。RGBでは赤196・緑136・青71。狐色は、中くらいの明るさではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

狐色を使うときの目安

白い文字3.0:1
黒い文字7.0:1

狐色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C48847;            /* 文字を狐色にする */
background-color: #C48847; /* 背景を狐色にする */

狐色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
