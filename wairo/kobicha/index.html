媚茶のカラーコード

#716246

もとは昆布の色を指す「昆布茶」。のちに「媚」の字があてられ、艶っぽい名前になりました。

媚茶（こびちゃ）のカラーコード（色番号・カラーナンバー）は #716246（「#」シャープつきの6桁の番号）です。RGBでは赤113・緑98・青70。媚茶は、暗めで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

媚茶を使うときの目安

白い文字5.9:1
黒い文字3.5:1

媚茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #716246;            /* 文字を媚茶にする */
background-color: #716246; /* 背景を媚茶にする */
