古代紫のカラーコード

#8C6589

昔ながらの紫根染めを思わせる、少し赤みがかった紫。「古代」は古風な趣を表します。

古代紫（こだいむらさき）のカラーコード（色番号・カラーナンバー）は #8C6589（「#」シャープつきの6桁の番号）です。RGBでは赤140・緑101・青137。古代紫は、中くらいの明るさで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

古代紫を使うときの目安

白い文字4.8:1
黒い文字4.3:1

古代紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #8C6589;            /* 文字を古代紫にする */
background-color: #8C6589; /* 背景を古代紫にする */
