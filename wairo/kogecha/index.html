焦茶のカラーコード

#6A4D32

物が焦げたような、黒みの強い茶色です。

焦茶（こげちゃ）のカラーコード（色番号・カラーナンバー）は #6A4D32（「#」シャープつきの6桁の番号）です。RGBでは赤106・緑77・青50。焦茶は、暗めで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

焦茶を使うときの目安

白い文字7.7:1
黒い文字2.7:1

焦茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6A4D32;            /* 文字を焦茶にする */
background-color: #6A4D32; /* 背景を焦茶にする */
