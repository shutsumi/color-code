琥珀色のカラーコード

#EA930A

樹脂が化石になった宝石・琥珀の色。ウイスキーの色のたとえにも使われます。

琥珀色（こはくいろ）のカラーコード（色番号・カラーナンバー）は #EA930A（「#」シャープつきの6桁の番号）です。RGBでは赤234・緑147・青10。琥珀色は、明るく鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

琥珀色を使うときの目安

白い文字2.4:1
黒い文字8.7:1

琥珀色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #EA930A;            /* 文字を琥珀色にする */
background-color: #EA930A; /* 背景を琥珀色にする */
