濃藍のカラーコード

#002E4E

藍染めを何度も重ねてつくる、もっとも濃い藍色の一つです。

濃藍（こいあい）のカラーコード（色番号・カラーナンバー）は #002E4E（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑46・青78。濃藍は、とても暗く落ち着いた青系の色です。「こあい」とも読みます。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

濃藍を使うときの目安

白い文字14.0:1
黒い文字1.5:1

濃藍の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 14.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #002E4E;            /* 文字を濃藍にする */
background-color: #002E4E; /* 背景を濃藍にする */

濃藍の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
