こけいろ

苔色のカラーコード

#78882D

しっとりとした苔の色。深く渋い黄緑です。

苔色（こけいろ）のカラーコード（色番号・カラーナンバー）は #78882D（「#」シャープつきの6桁の番号）です。RGBでは赤120・緑136・青45。苔色は、中くらいの明るさではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

苔色を使うときの目安

白い文字3.9:1
黒い文字5.4:1

苔色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #78882D;            /* 文字を苔色にする */
background-color: #78882D; /* 背景を苔色にする */

苔色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
