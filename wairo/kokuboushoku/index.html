国防色のカラーコード

#7B6C3E

昭和の日本陸軍の軍服の色。戦時中は国民服の色にもなりました。

国防色（こくぼうしょく）のカラーコード（色番号・カラーナンバー）は #7B6C3E（「#」シャープつきの6桁の番号）です。RGBでは赤123・緑108・青62。国防色は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

国防色を使うときの目安

白い文字5.2:1
黒い文字4.1:1

国防色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7B6C3E;            /* 文字を国防色にする */
background-color: #7B6C3E; /* 背景を国防色にする */
