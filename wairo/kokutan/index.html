黒檀のカラーコード

#250D00

重く硬い高級木材・黒檀の色。赤みを帯びた黒です。

黒檀（こくたん）のカラーコード（色番号・カラーナンバー）は #250D00（「#」シャープつきの6桁の番号）です。RGBでは赤37・緑13・青0。黒檀は、とても暗くくすんだ茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黒檀を使うときの目安

白い文字18.5:1
黒い文字1.1:1

黒檀の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 18.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #250D00;            /* 文字を黒檀にする */
background-color: #250D00; /* 背景を黒檀にする */

黒檀の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
