小麦色のカラーコード

#E4A343

実った小麦の粒の色。日焼けした肌を「小麦色の肌」と言うのもこの色です。

小麦色（こむぎいろ）のカラーコード（色番号・カラーナンバー）は #E4A343（「#」シャープつきの6桁の番号）です。RGBでは赤228・緑163・青67。小麦色は、明るくはっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

小麦色を使うときの目安

白い文字2.2:1
黒い文字9.6:1

小麦色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E4A343;            /* 文字を小麦色にする */
background-color: #E4A343; /* 背景を小麦色にする */

小麦色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
