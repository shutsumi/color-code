紺色のカラーコード

#233B6C

紺色（こんいろ）のカラーコード（色番号・カラーナンバー）は #233B6C（「#」シャープつきの6桁の番号）です。RGBでは赤35・緑59・青108。紺色は、とても暗く落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紺色を使うときの目安

白い文字11.0:1
黒い文字1.9:1

紺色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 11.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #233B6C;            /* 文字を紺色にする */
background-color: #233B6C; /* 背景を紺色にする */
