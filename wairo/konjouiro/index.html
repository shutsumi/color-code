紺青色のカラーコード

#1A4472

紺よりも明るく深い青。顔料の紺青（プルシアンブルー）は、北斎の浮世絵でも使われました。

紺青色（こんじょういろ）のカラーコード（色番号・カラーナンバー）は #1A4472（「#」シャープつきの6桁の番号）です。RGBでは赤26・緑68・青114。紺青色は、暗めで落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紺青色を使うときの目安

白い文字9.9:1
黒い文字2.1:1

紺青色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #1A4472;            /* 文字を紺青色にする */
background-color: #1A4472; /* 背景を紺青色にする */
