紺桔梗のカラーコード

#211E55

紺色を帯びた、濃い桔梗色。深い青紫です。

紺桔梗（こんききょう）のカラーコード（色番号・カラーナンバー）は #211E55（「#」シャープつきの6桁の番号）です。RGBでは赤33・緑30・青85。紺桔梗は、とても暗くはっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紺桔梗を使うときの目安

白い文字15.2:1
黒い文字1.4:1

紺桔梗の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 15.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #211E55;            /* 文字を紺桔梗にする */
background-color: #211E55; /* 背景を紺桔梗にする */
