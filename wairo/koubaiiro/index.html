紅梅色のカラーコード

#E86B79

早春に咲く紅梅の花の色。ほんのり紫を含んだ淡い紅です。

紅梅色（こうばいいろ）のカラーコード（色番号・カラーナンバー）は #E86B79（「#」シャープつきの6桁の番号）です。RGBでは赤232・緑107・青121。紅梅色は、中くらいの明るさではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紅梅色を使うときの目安

白い文字3.1:1
黒い文字6.8:1

紅梅色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E86B79;            /* 文字を紅梅色にする */
background-color: #E86B79; /* 背景を紅梅色にする */
