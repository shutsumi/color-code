香色のカラーコード

#EFCD9A

丁子（クローブ）などの香木を煮出して染めた色。染めた布からほのかに香りが立ちました。

香色（こういろ）のカラーコード（色番号・カラーナンバー）は #EFCD9A（「#」シャープつきの6桁の番号）です。RGBでは赤239・緑205・青154。香色は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

香色を使うときの目安

白い文字1.5:1
黒い文字13.9:1

香色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 13.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #EFCD9A;            /* 文字を香色にする */
background-color: #EFCD9A; /* 背景を香色にする */
