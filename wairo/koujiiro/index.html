柑子色のカラーコード

#FF5234

日本の古い小ぶりのみかん「柑子（こうじ）」の実の色。明るい橙です。

柑子色（こうじいろ）のカラーコード（色番号・カラーナンバー）は #FF5234（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑82・青52。柑子色は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

柑子色を使うときの目安

白い文字3.2:1
黒い文字6.5:1

柑子色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FF5234;            /* 文字を柑子色にする */
background-color: #FF5234; /* 背景を柑子色にする */

柑子色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
