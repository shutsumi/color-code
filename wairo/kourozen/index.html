黄櫨染のカラーコード

#D99502

ハゼノキと蘇芳で染めた色。天皇だけが着られる最高位の禁色で、即位の礼の装束にも使われます。

黄櫨染（こうろぜん）のカラーコード（色番号・カラーナンバー）は #D99502（「#」シャープつきの6桁の番号）です。RGBでは赤217・緑149・青2。黄櫨染は、明るく鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黄櫨染を使うときの目安

白い文字2.5:1
黒い文字8.3:1

黄櫨染の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #D99502;            /* 文字を黄櫨染にする */
background-color: #D99502; /* 背景を黄櫨染にする */
