梔子色のカラーコード

#FFD768

クチナシの実で染めた黄色。実が熟しても口を開かないことから「口無し」と呼ばれます。

梔子色（くちなしいろ）のカラーコード（色番号・カラーナンバー）は #FFD768（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑215・青104。梔子色は、とても明るくはっきりした黄系の色です。

別の書き方：支子色

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

同じカラーコードで載っている色：苅安色

梔子色を使うときの目安

白い文字1.4:1
黒い文字15.2:1

梔子色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 15.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFD768;            /* 文字を梔子色にする */
background-color: #FFD768; /* 背景を梔子色にする */
