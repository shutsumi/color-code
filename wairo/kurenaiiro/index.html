紅色のカラーコード

#C22047

紅色（くれないいろ）のカラーコード（色番号・カラーナンバー）は #C22047（「#」シャープつきの6桁の番号）です。RGBでは赤194・緑32・青71。紅色は、暗めで鮮やかな赤系の色です。「べにいろ」とも読みます。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紅色を使うときの目安

白い文字5.8:1
黒い文字3.6:1

紅色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C22047;            /* 文字を紅色にする */
background-color: #C22047; /* 背景を紅色にする */
