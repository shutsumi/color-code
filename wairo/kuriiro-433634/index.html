くりいろ

涅色のカラーコード

#433634

川や池の底にたまる黒い泥「涅（くり）」の色。お坊さんの衣にも使われました。

涅色（くりいろ）のカラーコード（色番号・カラーナンバー）は #433634（「#」シャープつきの6桁の番号）です。RGBでは赤67・緑54・青52。涅色は、とても暗くくすんだ赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

涅色を使うときの目安

白い文字11.6:1
黒い文字1.8:1

涅色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 11.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #433634;            /* 文字を涅色にする */
background-color: #433634; /* 背景を涅色にする */

涅色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
