くりいろ

栗色のカラーコード

#800000

栗の実の皮の色。つやのある赤みの焦げ茶です。

栗色（くりいろ）のカラーコード（色番号・カラーナンバー）は #800000（「#」シャープつきの6桁の番号）です。RGBでは赤128・緑0・青0。栗色は、とても暗く鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

栗色を使うときの目安

白い文字10.9:1
黒い文字1.9:1

栗色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 10.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #800000;            /* 文字を栗色にする */
background-color: #800000; /* 背景を栗色にする */

栗色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
