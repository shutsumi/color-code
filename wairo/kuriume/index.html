栗梅のカラーコード

#6C1912

栗色を帯びた赤茶色。江戸時代に好まれた色の一つです。

栗梅（くりうめ）のカラーコード（色番号・カラーナンバー）は #6C1912（「#」シャープつきの6桁の番号）です。RGBでは赤108・緑25・青18。栗梅は、とても暗くはっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

栗梅を使うときの目安

白い文字11.8:1
黒い文字1.8:1

栗梅の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 11.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6C1912;            /* 文字を栗梅にする */
background-color: #6C1912; /* 背景を栗梅にする */

栗梅の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
