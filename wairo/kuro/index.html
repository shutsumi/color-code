くろ

黒のカラーコード

#000000

日本語の基本の色名の一つ。一説に「暗（くら）い」と同じ根から生まれたといわれます。

黒（くろ）のカラーコード（色番号・カラーナンバー）は #000000（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑0・青0。黒は、黒に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黒を使うときの目安

白い文字21.0:1
黒い文字1.0:1

黒の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 21.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #000000;            /* 文字を黒にする */
background-color: #000000; /* 背景を黒にする */

黒の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
