草色のカラーコード

#7B8D42

夏の生い茂った草の色。若草色より濃く、くすんだ黄緑です。

草色（くさいろ）のカラーコード（色番号・カラーナンバー）は #7B8D42（「#」シャープつきの6桁の番号）です。RGBでは赤123・緑141・青66。草色は、中くらいの明るさではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

草色を使うときの目安

白い文字3.7:1
黒い文字5.7:1

草色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7B8D42;            /* 文字を草色にする */
background-color: #7B8D42; /* 背景を草色にする */

草色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
