くわぞめ

桑染のカラーコード

#DABC91

桑の木の根や樹皮で染めた色。くすんだ黄みの茶です。

桑染（くわぞめ）のカラーコード（色番号・カラーナンバー）は #DABC91（「#」シャープつきの6桁の番号）です。RGBでは赤218・緑188・青145。桑染は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

桑染を使うときの目安

白い文字1.8:1
黒い文字11.6:1

桑染の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #DABC91;            /* 文字を桑染にする */
background-color: #DABC91; /* 背景を桑染にする */
