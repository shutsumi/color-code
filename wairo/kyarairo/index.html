伽羅色のカラーコード

#D8A373

香木の最高級品「伽羅」の色。暗めの黄みの茶です。

伽羅色（きゃらいろ）のカラーコード（色番号・カラーナンバー）は #D8A373（「#」シャープつきの6桁の番号）です。RGBでは赤216・緑163・青115。伽羅色は、明るくはっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

伽羅色を使うときの目安

白い文字2.2:1
黒い文字9.4:1

伽羅色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #D8A373;            /* 文字を伽羅色にする */
background-color: #D8A373; /* 背景を伽羅色にする */
