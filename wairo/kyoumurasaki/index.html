きょうむらさき

京紫のカラーコード

#772F6D

京都で染められた紫。赤みがかった紫で、青みの江戸紫と対にされます。

京紫（きょうむらさき）のカラーコード（色番号・カラーナンバー）は #772F6D（「#」シャープつきの6桁の番号）です。RGBでは赤119・緑47・青109。京紫は、暗めではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

京紫を使うときの目安

白い文字8.7:1
黒い文字2.4:1

京紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 8.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #772F6D;            /* 文字を京紫にする */
background-color: #772F6D; /* 背景を京紫にする */
