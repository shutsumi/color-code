紛紅のカラーコード

#FB3C02

蘇芳を使って紅花の紅に似せて染めた色。「まがい物の紅」という意味です。

紛紅（まがいべに）のカラーコード（色番号・カラーナンバー）は #FB3C02（「#」シャープつきの6桁の番号）です。RGBでは赤251・緑60・青2。紛紅は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紛紅を使うときの目安

白い文字3.7:1
黒い文字5.7:1

紛紅の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FB3C02;            /* 文字を紛紅にする */
background-color: #FB3C02; /* 背景を紛紅にする */
