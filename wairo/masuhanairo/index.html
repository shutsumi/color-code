枡花色のカラーコード

#5B7E91

五代目市川團十郎が好んだ淡い青。團十郎家の紋「三升（みます）」にちなむ名前です。

枡花色（ますはないろ）のカラーコード（色番号・カラーナンバー）は #5B7E91（「#」シャープつきの6桁の番号）です。RGBでは赤91・緑126・青145。枡花色は、中くらいの明るさでくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

枡花色を使うときの目安

白い文字4.3:1
黒い文字4.8:1

枡花色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 4.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #5B7E91;            /* 文字を枡花色にする */
background-color: #5B7E91; /* 背景を枡花色にする */

枡花色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
