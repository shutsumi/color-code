松葉色のカラーコード

#3F7735

松の葉の色。くすんだ緑で、長寿の縁起色とされます。

松葉色（まつばいろ）のカラーコード（色番号・カラーナンバー）は #3F7735（「#」シャープつきの6桁の番号）です。RGBでは赤63・緑119・青53。松葉色は、暗めではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

松葉色を使うときの目安

白い文字5.4:1
黒い文字3.9:1

松葉色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #3F7735;            /* 文字を松葉色にする */
background-color: #3F7735; /* 背景を松葉色にする */
