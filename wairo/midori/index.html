みどり

緑のカラーコード

#008000

もとは新芽や若枝を指した言葉。みずみずしいものを表し、「みどりの黒髪」という言い方もあります。

緑（みどり）のカラーコード（色番号・カラーナンバー）は #008000（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑128・青0。緑は、中くらいの明るさで鮮やかな緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

緑を使うときの目安

白い文字5.1:1
黒い文字4.1:1

緑の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #008000;            /* 文字を緑にする */
background-color: #008000; /* 背景を緑にする */
