蜜柑色のカラーコード

#F08300

蜜柑色（みかんいろ）のカラーコード（色番号・カラーナンバー）は #F08300（「#」シャープつきの6桁の番号）です。RGBでは赤240・緑131・青0。蜜柑色は、明るく鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

蜜柑色を使うときの目安

白い文字2.6:1
黒い文字8.0:1

蜜柑色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F08300;            /* 文字を蜜柑色にする */
background-color: #F08300; /* 背景を蜜柑色にする */
