海松色のカラーコード

#6E6B41

海藻の一種・ミルの色。灰色がかった黄緑です。

海松色（みるいろ）のカラーコード（色番号・カラーナンバー）は #6E6B41（「#」シャープつきの6桁の番号）です。RGBでは赤110・緑107・青65。海松色は、暗めで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

海松色を使うときの目安

白い文字5.5:1
黒い文字3.8:1

海松色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6E6B41;            /* 文字を海松色にする */
background-color: #6E6B41; /* 背景を海松色にする */
