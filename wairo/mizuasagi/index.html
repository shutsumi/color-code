水浅葱のカラーコード

#8CD2BC

水色がかった浅葱色。浅葱色をさらに淡くした青緑です。

水浅葱（みずあさぎ）のカラーコード（色番号・カラーナンバー）は #8CD2BC（「#」シャープつきの6桁の番号）です。RGBでは赤140・緑210・青188。水浅葱は、明るく落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

水浅葱を使うときの目安

白い文字1.7:1
黒い文字12.1:1

水浅葱の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #8CD2BC;            /* 文字を水浅葱にする */
background-color: #8CD2BC; /* 背景を水浅葱にする */

水浅葱の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
