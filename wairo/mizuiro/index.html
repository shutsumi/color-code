みずいろ

水色のカラーコード

#AFDFE4

澄んだ水の色。淡く、わずかに緑みのある青です。

水色（みずいろ）のカラーコード（色番号・カラーナンバー）は #AFDFE4（「#」シャープつきの6桁の番号）です。RGBでは赤175・緑223・青228。水色は、とても明るくくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

水色を使うときの目安

白い文字1.4:1
黒い文字14.5:1

水色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 14.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AFDFE4;            /* 文字を水色にする */
background-color: #AFDFE4; /* 背景を水色にする */

水色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
