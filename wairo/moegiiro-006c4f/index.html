萌葱色のカラーコード

#006C4F

ネギの芽の色。萌黄色より青みの強い、鮮やかな緑です。

萌葱色（もえぎいろ）のカラーコード（色番号・カラーナンバー）は #006C4F（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑108・青79。萌葱色は、暗めではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

萌葱色を使うときの目安

白い文字6.4:1
黒い文字3.3:1

萌葱色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #006C4F;            /* 文字を萌葱色にする */
background-color: #006C4F; /* 背景を萌葱色にする */
