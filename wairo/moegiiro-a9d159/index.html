萌黄色のカラーコード

#A9D159

萌黄色（もえぎいろ）のカラーコード（色番号・カラーナンバー）は #A9D159（「#」シャープつきの6桁の番号）です。RGBでは赤169・緑209・青89。萌黄色は、明るく鮮やかな緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

萌黄色を使うときの目安

白い文字1.8:1
黒い文字12.0:1

萌黄色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A9D159;            /* 文字を萌黄色にする */
background-color: #A9D159; /* 背景を萌黄色にする */
