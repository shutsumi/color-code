木蘭色のカラーコード

#C7B370

樹皮で染めた黄みの茶。僧侶の衣の色として使われてきました。

木蘭色（もくらんいろ）のカラーコード（色番号・カラーナンバー）は #C7B370（「#」シャープつきの6桁の番号）です。RGBでは赤199・緑179・青112。木蘭色は、明るくはっきりした黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

木蘭色を使うときの目安

白い文字2.1:1
黒い文字10.1:1

木蘭色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C7B370;            /* 文字を木蘭色にする */
background-color: #C7B370; /* 背景を木蘭色にする */
