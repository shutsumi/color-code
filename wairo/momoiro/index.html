桃色のカラーコード

#F58F98

春に咲く桃の花の色。明るく淡い紅です。

桃色（ももいろ）のカラーコード（色番号・カラーナンバー）は #F58F98（「#」シャープつきの6桁の番号）です。RGBでは赤245・緑143・青152。桃色は、明るくはっきりしたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

桃色を使うときの目安

白い文字2.3:1
黒い文字9.3:1

桃色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F58F98;            /* 文字を桃色にする */
background-color: #F58F98; /* 背景を桃色にする */

桃色の薄い色・濃い色
