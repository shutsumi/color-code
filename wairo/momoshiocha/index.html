百塩茶のカラーコード

#542D24

「百塩（ももしお）」は染め液に何度も浸すこと。染め重ねてできる、とても濃い赤茶です。

百塩茶（ももしおちゃ）のカラーコード（色番号・カラーナンバー）は #542D24（「#」シャープつきの6桁の番号）です。RGBでは赤84・緑45・青36。百塩茶は、とても暗く落ち着いた赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

百塩茶を使うときの目安

白い文字11.8:1
黒い文字1.8:1

百塩茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 11.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #542D24;            /* 文字を百塩茶にする */
background-color: #542D24; /* 背景を百塩茶にする */
