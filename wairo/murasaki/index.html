むらさき

紫のカラーコード

#A757A8

ムラサキという草の根（紫根）で染めた色。古くから最も高貴な色とされてきました。

紫（むらさき）のカラーコード（色番号・カラーナンバー）は #A757A8（「#」シャープつきの6桁の番号）です。RGBでは赤167・緑87・青168。紫は、中くらいの明るさではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紫を使うときの目安

白い文字4.6:1
黒い文字4.6:1

紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A757A8;            /* 文字を紫にする */
background-color: #A757A8; /* 背景を紫にする */
