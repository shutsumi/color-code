紫鈍のカラーコード

#966F9C

紫を帯びた鈍色（にびいろ）。紫みの灰色です。

紫鈍（むらさきにび）のカラーコード（色番号・カラーナンバー）は #966F9C（「#」シャープつきの6桁の番号）です。RGBでは赤150・緑111・青156。紫鈍は、中くらいの明るさで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紫鈍を使うときの目安

白い文字4.2:1
黒い文字5.1:1

紫鈍の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #966F9C;            /* 文字を紫鈍にする */
background-color: #966F9C; /* 背景を紫鈍にする */

紫鈍の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
