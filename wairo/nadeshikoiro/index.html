撫子色のカラーコード

#F6ADC6

撫子色（なでしこいろ）のカラーコード（色番号・カラーナンバー）は #F6ADC6（「#」シャープつきの6桁の番号）です。RGBでは赤246・緑173・青198。撫子色は、明るく落ち着いたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

撫子色を使うときの目安

白い文字1.8:1
黒い文字11.7:1

撫子色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F6ADC6;            /* 文字を撫子色にする */
background-color: #F6ADC6; /* 背景を撫子色にする */
