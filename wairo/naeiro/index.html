苗色のカラーコード

#B0CA71

苗色（なえいろ）のカラーコード（色番号・カラーナンバー）は #B0CA71（「#」シャープつきの6桁の番号）です。RGBでは赤176・緑202・青113。苗色は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

苗色を使うときの目安

白い文字1.8:1
黒い文字11.5:1

苗色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B0CA71;            /* 文字を苗色にする */
background-color: #B0CA71; /* 背景を苗色にする */
