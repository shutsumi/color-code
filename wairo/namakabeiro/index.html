なまかべいろ

生壁色のカラーコード

#AA8C63

塗ったばかりでまだ乾いていない土壁の色。灰色みのある黄みの茶です。

生壁色（なまかべいろ）のカラーコード（色番号・カラーナンバー）は #AA8C63（「#」シャープつきの6桁の番号）です。RGBでは赤170・緑140・青99。生壁色は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

生壁色を使うときの目安

白い文字3.2:1
黒い文字6.6:1

生壁色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AA8C63;            /* 文字を生壁色にする */
background-color: #AA8C63; /* 背景を生壁色にする */

生壁色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
