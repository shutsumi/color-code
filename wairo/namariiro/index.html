鉛色のカラーコード

#7B7C7D

鉛色（なまりいろ）のカラーコード（色番号・カラーナンバー）は #7B7C7D（「#」シャープつきの6桁の番号）です。RGBでは赤123・緑124・青125。鉛色は、灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鉛色を使うときの目安

白い文字4.2:1
黒い文字5.0:1

鉛色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7B7C7D;            /* 文字を鉛色にする */
background-color: #7B7C7D; /* 背景を鉛色にする */
