納戸色のカラーコード

#008899

物をしまう「納戸」の薄暗さを思わせる、緑みの深い青。納戸の垂れ幕の色が由来という説もあります。

納戸色（なんどいろ）のカラーコード（色番号・カラーナンバー）は #008899（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑136・青153。納戸色は、中くらいの明るさで落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

納戸色を使うときの目安

白い文字4.2:1
黒い文字5.0:1

納戸色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #008899;            /* 文字を納戸色にする */
background-color: #008899; /* 背景を納戸色にする */

納戸色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
