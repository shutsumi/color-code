菜の花色のカラーコード

#FCD900

菜の花色（なのはないろ）のカラーコード（色番号・カラーナンバー）は #FCD900（「#」シャープつきの6桁の番号）です。RGBでは赤252・緑217・青0。菜の花色は、とても明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

菜の花色を使うときの目安

白い文字1.4:1
黒い文字15.1:1

菜の花色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 15.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FCD900;            /* 文字を菜の花色にする */
background-color: #FCD900; /* 背景を菜の花色にする */
