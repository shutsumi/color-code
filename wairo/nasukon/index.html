茄子紺のカラーコード

#824880

茄子紺（なすこん）のカラーコード（色番号・カラーナンバー）は #824880（「#」シャープつきの6桁の番号）です。RGBでは赤130・緑72・青128。茄子紺は、暗めではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

茄子紺を使うときの目安

白い文字6.6:1
黒い文字3.2:1

茄子紺の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #824880;            /* 文字を茄子紺にする */
background-color: #824880; /* 背景を茄子紺にする */
