根岸色のカラーコード

#908E65

根岸色（ねぎしいろ）のカラーコード（色番号・カラーナンバー）は #908E65（「#」シャープつきの6桁の番号）です。RGBでは赤144・緑142・青101。根岸色は、中くらいの明るさで落ち着いた黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

根岸色を使うときの目安

白い文字3.4:1
黒い文字6.2:1

根岸色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #908E65;            /* 文字を根岸色にする */
background-color: #908E65; /* 背景を根岸色にする */
