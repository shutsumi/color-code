ねりいろ

練色のカラーコード

#FFF9E2

生糸を練って柔らかくした「練糸」の色。わずかに黄みを帯びた白です。

練色（ねりいろ）のカラーコード（色番号・カラーナンバー）は #FFF9E2（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑249・青226。練色は、とても明るくくすんだ黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

練色を使うときの目安

白い文字1.1:1
黒い文字19.9:1

練色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 19.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFF9E2;            /* 文字を練色にする */
background-color: #FFF9E2; /* 背景を練色にする */

練色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
