ねずみいろ

鼠色のカラーコード

#949495

ネズミの毛の色から。江戸時代には何十種類もの「鼠」の付く色が生まれました。

鼠色（ねずみいろ）のカラーコード（色番号・カラーナンバー）は #949495（「#」シャープつきの6桁の番号）です。RGBでは赤148・緑148・青149。鼠色は、灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鼠色を使うときの目安

白い文字3.0:1
黒い文字6.9:1

鼠色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #949495;            /* 文字を鼠色にする */
background-color: #949495; /* 背景を鼠色にする */
