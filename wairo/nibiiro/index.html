鈍色のカラーコード

#727171

濃い灰色。平安時代には喪に服すときの衣の色でした。「鈍（にび）」は色がくすんだ様子です。

鈍色（にびいろ）のカラーコード（色番号・カラーナンバー）は #727171（「#」シャープつきの6桁の番号）です。RGBでは赤114・緑113・青113。鈍色は、灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鈍色を使うときの目安

白い文字4.9:1
黒い文字4.3:1

鈍色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #727171;            /* 文字を鈍色にする */
background-color: #727171; /* 背景を鈍色にする */
