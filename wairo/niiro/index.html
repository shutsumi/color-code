丹色のカラーコード

#E45E32

「丹（に）」は赤い土のこと。神社や寺の丹塗りに使われてきた赤です。

丹色（にいろ）のカラーコード（色番号・カラーナンバー）は #E45E32（「#」シャープつきの6桁の番号）です。RGBでは赤228・緑94・青50。丹色は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

丹色を使うときの目安

白い文字3.5:1
黒い文字5.9:1

丹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E45E32;            /* 文字を丹色にする */
background-color: #E45E32; /* 背景を丹色にする */
