似紫のカラーコード

#513743

高価な紫根の代わりに、藍と蘇芳を重ねて紫に似せて染めた色。「似せ紫」という意味です。

似紫（にせむらさき）のカラーコード（色番号・カラーナンバー）は #513743（「#」シャープつきの6桁の番号）です。RGBでは赤81・緑55・青67。似紫は、とても暗くくすんだ赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

似紫を使うときの目安

白い文字10.6:1
黒い文字2.0:1

似紫の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 10.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #513743;            /* 文字を似紫にする */
background-color: #513743; /* 背景を似紫にする */
