濡烏のカラーコード

#000B00

水に濡れたカラスの羽のような、つやのある黒。女性の美しい黒髪のたとえにも使われます。

濡烏（ぬれがらす）のカラーコード（色番号・カラーナンバー）は #000B00（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑11・青0。濡烏は、とても暗くくすんだ緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

濡烏を使うときの目安

白い文字20.0:1
黒い文字1.0:1

濡烏の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 20.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #000B00;            /* 文字を濡烏にする */
background-color: #000B00; /* 背景を濡烏にする */

濡烏の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
