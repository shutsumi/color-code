乳白色のカラーコード

#FFFFFB

牛乳のような、にごりのある白です。

乳白色（にゅうはくしょく）のカラーコード（色番号・カラーナンバー）は #FFFFFB（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑255・青251。乳白色は、白に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

乳白色を使うときの目安

白い文字1.0:1
黒い文字20.9:1

乳白色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 20.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFFFFB;            /* 文字を乳白色にする */
background-color: #FFFFFB; /* 背景を乳白色にする */

乳白色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
