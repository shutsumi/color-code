老竹色のカラーコード

#769164

年を経て色が落ち着いた竹の色。若い竹に比べて、灰色がかった緑です。

老竹色（おいたけいろ）のカラーコード（色番号・カラーナンバー）は #769164（「#」シャープつきの6桁の番号）です。RGBでは赤118・緑145・青100。老竹色は、中くらいの明るさで落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

老竹色を使うときの目安

白い文字3.5:1
黒い文字6.0:1

老竹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #769164;            /* 文字を老竹色にする */
background-color: #769164; /* 背景を老竹色にする */
