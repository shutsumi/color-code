織部色のカラーコード

#125115

茶人・古田織部が好んだ焼き物「織部焼」の緑の釉薬から名づけられた色です。

織部色（おりべいろ）のカラーコード（色番号・カラーナンバー）は #125115（「#」シャープつきの6桁の番号）です。RGBでは赤18・緑81・青21。織部色は、暗めではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

織部色を使うときの目安

白い文字9.5:1
黒い文字2.2:1

織部色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #125115;            /* 文字を織部色にする */
background-color: #125115; /* 背景を織部色にする */
