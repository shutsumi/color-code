楝色のカラーコード

#A596C7

楝色（おうちいろ）のカラーコード（色番号・カラーナンバー）は #A596C7（「#」シャープつきの6桁の番号）です。RGBでは赤165・緑150・青199。楝色は、中くらいの明るさで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

楝色を使うときの目安

白い文字2.7:1
黒い文字7.8:1

楝色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A596C7;            /* 文字を楝色にする */
background-color: #A596C7; /* 背景を楝色にする */
