黄丹のカラーコード

#F47A55

紅花とクチナシで染めた橙色。皇太子だけが着られる「禁色」として今も受け継がれています。

黄丹（おうに）のカラーコード（色番号・カラーナンバー）は #F47A55（「#」シャープつきの6桁の番号）です。RGBでは赤244・緑122・青85。黄丹は、中くらいの明るさで鮮やかな橙・オレンジ系の色です。「おうたん」とも読みます。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

黄丹を使うときの目安

白い文字2.7:1
黒い文字7.8:1

黄丹の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F47A55;            /* 文字を黄丹にする */
background-color: #F47A55; /* 背景を黄丹にする */
