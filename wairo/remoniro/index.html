れもんいろ

檸檬色のカラーコード

#FFF450

レモンの皮の色。やや緑みを帯びた明るい黄色です。

檸檬色（れもんいろ）のカラーコード（色番号・カラーナンバー）は #FFF450（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑244・青80。檸檬色は、とても明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

檸檬色を使うときの目安

白い文字1.1:1
黒い文字18.3:1

檸檬色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 18.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFF450;            /* 文字を檸檬色にする */
background-color: #FFF450; /* 背景を檸檬色にする */

檸檬色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
