煉瓦色のカラーコード

#AA5C3F

焼き物の煉瓦の色。明治の洋館や駅舎を思わせる、赤みのくすんだ茶です。

煉瓦色（れんがいろ）のカラーコード（色番号・カラーナンバー）は #AA5C3F（「#」シャープつきの6桁の番号）です。RGBでは赤170・緑92・青63。煉瓦色は、中くらいの明るさではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

煉瓦色を使うときの目安

白い文字4.9:1
黒い文字4.3:1

煉瓦色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AA5C3F;            /* 文字を煉瓦色にする */
background-color: #AA5C3F; /* 背景を煉瓦色にする */

煉瓦色の薄い色・濃い色
