璃寛茶のカラーコード

#6E6636

大坂の歌舞伎役者・二代目嵐吉三郎（俳名・璃寛）が好んだ、暗い緑みの茶。役者の名が付いた流行色です。

璃寛茶（りかんちゃ）のカラーコード（色番号・カラーナンバー）は #6E6636（「#」シャープつきの6桁の番号）です。RGBでは赤110・緑102・青54。璃寛茶は、暗めで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

璃寛茶を使うときの目安

白い文字5.8:1
黒い文字3.6:1

璃寛茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6E6636;            /* 文字を璃寛茶にする */
background-color: #6E6636; /* 背景を璃寛茶にする */
