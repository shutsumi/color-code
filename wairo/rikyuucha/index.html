利休茶のカラーコード

#897845

茶人・千利休の名を冠した、緑がかった薄茶。わび・さびを感じさせる色として江戸時代に名づけられました。

利休茶（りきゅうちゃ）のカラーコード（色番号・カラーナンバー）は #897845（「#」シャープつきの6桁の番号）です。RGBでは赤137・緑120・青69。利休茶は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

利休茶を使うときの目安

白い文字4.3:1
黒い文字4.8:1

利休茶の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 4.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #897845;            /* 文字を利休茶にする */
background-color: #897845; /* 背景を利休茶にする */
