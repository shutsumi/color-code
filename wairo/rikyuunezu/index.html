利休鼠のカラーコード

#888E7E

千利休を思わせる、緑がかった鼠色。北原白秋の詩「城ヶ島の雨」にも登場します。

利休鼠（りきゅうねず）のカラーコード（色番号・カラーナンバー）は #888E7E（「#」シャープつきの6桁の番号）です。RGBでは赤136・緑142・青126。利休鼠は、中くらいの明るさでくすんだ緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

利休鼠を使うときの目安

白い文字3.4:1
黒い文字6.2:1

利休鼠の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #888E7E;            /* 文字を利休鼠にする */
background-color: #888E7E; /* 背景を利休鼠にする */

利休鼠の薄い色・濃い色
