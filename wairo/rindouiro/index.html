竜胆色のカラーコード

#6967AB

秋に咲くリンドウの花の色。薄い青紫です。

竜胆色（りんどういろ）のカラーコード（色番号・カラーナンバー）は #6967AB（「#」シャープつきの6桁の番号）です。RGBでは赤105・緑103・青171。竜胆色は、中くらいの明るさではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

竜胆色を使うときの目安

白い文字5.1:1
黒い文字4.1:1

竜胆色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6967AB;            /* 文字を竜胆色にする */
background-color: #6967AB; /* 背景を竜胆色にする */
