呂色のカラーコード

#0C0C0C

漆塗りの「呂色（ろいろ）」に由来する黒。落ち着いた深い黒です。

呂色（ろいろ）のカラーコード（色番号・カラーナンバー）は #0C0C0C（「#」シャープつきの6桁の番号）です。RGBでは赤12・緑12・青12。呂色は、黒に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

呂色を使うときの目安

白い文字19.6:1
黒い文字1.1:1

呂色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 19.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #0C0C0C;            /* 文字を呂色にする */
background-color: #0C0C0C; /* 背景を呂色にする */

呂色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
