路考茶のカラーコード

#8C7042

路考茶（ろこうちゃ）のカラーコード（色番号・カラーナンバー）は #8C7042（「#」シャープつきの6桁の番号）です。RGBでは赤140・緑112・青66。路考茶は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

路考茶を使うときの目安

白い文字4.7:1
黒い文字4.5:1

路考茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #8C7042;            /* 文字を路考茶にする */
background-color: #8C7042; /* 背景を路考茶にする */
