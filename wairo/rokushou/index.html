緑青のカラーコード

#5BAD92

緑青（ろくしょう）のカラーコード（色番号・カラーナンバー）は #5BAD92（「#」シャープつきの6桁の番号）です。RGBでは赤91・緑173・青146。緑青は、明るく落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

緑青を使うときの目安

白い文字2.7:1
黒い文字7.8:1

緑青の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #5BAD92;            /* 文字を緑青にする */
background-color: #5BAD92; /* 背景を緑青にする */
