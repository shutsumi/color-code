瑠璃色のカラーコード

#2A5CAA

宝石・瑠璃（ラピスラズリ）の色。仏教の七宝の一つに数えられる、深い青です。

瑠璃色（るりいろ）のカラーコード（色番号・カラーナンバー）は #2A5CAA（「#」シャープつきの6桁の番号）です。RGBでは赤42・緑92・青170。瑠璃色は、暗めではっきりした青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

瑠璃色を使うときの目安

白い文字6.5:1
黒い文字3.2:1

瑠璃色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #2A5CAA;            /* 文字を瑠璃色にする */
background-color: #2A5CAA; /* 背景を瑠璃色にする */
