瑠璃紺のカラーコード

#224B8F

瑠璃色を帯びた紺。深い紫みの青です。

瑠璃紺（るりこん）のカラーコード（色番号・カラーナンバー）は #224B8F（「#」シャープつきの6桁の番号）です。RGBでは赤34・緑75・青143。瑠璃紺は、暗めではっきりした青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

瑠璃紺を使うときの目安

白い文字8.5:1
黒い文字2.5:1

瑠璃紺の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 8.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #224B8F;            /* 文字を瑠璃紺にする */
background-color: #224B8F; /* 背景を瑠璃紺にする */
