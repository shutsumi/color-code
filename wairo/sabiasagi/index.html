錆浅葱のカラーコード

#5C9291

浅葱色がくすんで、錆びたように落ち着いた色。「錆」は渋くくすんだ様子を表します。

錆浅葱（さびあさぎ）のカラーコード（色番号・カラーナンバー）は #5C9291（「#」シャープつきの6桁の番号）です。RGBでは赤92・緑146・青145。錆浅葱は、中くらいの明るさで落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

錆浅葱を使うときの目安

白い文字3.5:1
黒い文字6.0:1

錆浅葱の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #5C9291;            /* 文字を錆浅葱にする */
background-color: #5C9291; /* 背景を錆浅葱にする */

錆浅葱の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
