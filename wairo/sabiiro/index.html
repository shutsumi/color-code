さびいろ

錆色のカラーコード

#6C3424

鉄が錆びたときの赤茶色です。

錆色（さびいろ）のカラーコード（色番号・カラーナンバー）は #6C3424（「#」シャープつきの6桁の番号）です。RGBでは赤108・緑52・青36。錆色は、暗めで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

錆色を使うときの目安

白い文字9.7:1
黒い文字2.2:1

錆色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6C3424;            /* 文字を錆色にする */
background-color: #6C3424; /* 背景を錆色にする */
