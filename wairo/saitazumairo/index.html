左伊多津万色のカラーコード

#328131

野草イタドリの葉の色。「左伊多津万」は、イタドリを万葉仮名のように書いた当て字です。

左伊多津万色（さいたづまいろ）のカラーコード（色番号・カラーナンバー）は #328131（「#」シャープつきの6桁の番号）です。RGBでは赤50・緑129・青49。左伊多津万色は、中くらいの明るさではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

左伊多津万色を使うときの目安

白い文字4.9:1
黒い文字4.3:1

左伊多津万色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #328131;            /* 文字を左伊多津万色にする */
background-color: #328131; /* 背景を左伊多津万色にする */
