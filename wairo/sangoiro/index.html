珊瑚色のカラーコード

#FF7F50

赤いサンゴを砕いた顔料の色。明るい黄みの赤で、コーラルピンクにあたります。

珊瑚色（さんごいろ）のカラーコード（色番号・カラーナンバー）は #FF7F50（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑127・青80。珊瑚色は、明るく鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

珊瑚色を使うときの目安

白い文字2.5:1
黒い文字8.4:1

珊瑚色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FF7F50;            /* 文字を珊瑚色にする */
background-color: #FF7F50; /* 背景を珊瑚色にする */
