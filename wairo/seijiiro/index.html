青磁色のカラーコード

#60B49F

中国から伝わった焼き物・青磁の釉薬の色。淡く青みがかった緑です。

青磁色（せいじいろ）のカラーコード（色番号・カラーナンバー）は #60B49F（「#」シャープつきの6桁の番号）です。RGBでは赤96・緑180・青159。青磁色は、明るく落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

青磁色を使うときの目安

白い文字2.5:1
黒い文字8.5:1

青磁色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #60B49F;            /* 文字を青磁色にする */
background-color: #60B49F; /* 背景を青磁色にする */
