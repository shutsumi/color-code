石竹色のカラーコード

#F9C1CF

石竹色（せきちくいろ）のカラーコード（色番号・カラーナンバー）は #F9C1CF（「#」シャープつきの6桁の番号）です。RGBでは赤249・緑193・青207。石竹色は、明るく落ち着いたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

石竹色を使うときの目安

白い文字1.5:1
黒い文字13.6:1

石竹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 13.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F9C1CF;            /* 文字を石竹色にする */
background-color: #F9C1CF; /* 背景を石竹色にする */
