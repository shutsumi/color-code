仙斎茶のカラーコード

#474B42

「千歳茶」とも書き、千年変わらない松の緑を思わせる暗い緑みの茶です。

仙斎茶（せんさいちゃ）のカラーコード（色番号・カラーナンバー）は #474B42（「#」シャープつきの6桁の番号）です。RGBでは赤71・緑75・青66。仙斎茶は、暗めでくすんだ緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

仙斎茶を使うときの目安

白い文字8.9:1
黒い文字2.4:1

仙斎茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 8.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #474B42;            /* 文字を仙斎茶にする */
background-color: #474B42; /* 背景を仙斎茶にする */
