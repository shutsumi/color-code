赤銅色のカラーコード

#7E0F09

銅に金を少し混ぜた合金・赤銅の色。日焼けした肌を「赤銅色の肌」と言います。

赤銅色（しゃくどういろ）のカラーコード（色番号・カラーナンバー）は #7E0F09（「#」シャープつきの6桁の番号）です。RGBでは赤126・緑15・青9。赤銅色は、とても暗くはっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

赤銅色を使うときの目安

白い文字10.7:1
黒い文字2.0:1

赤銅色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 10.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7E0F09;            /* 文字を赤銅色にする */
background-color: #7E0F09; /* 背景を赤銅色にする */
