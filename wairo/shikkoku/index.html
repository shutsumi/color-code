漆黒のカラーコード

#080000

黒漆を塗ったような、深くつやのある黒。もっとも黒い黒のたとえです。

漆黒（しっこく）のカラーコード（色番号・カラーナンバー）は #080000（「#」シャープつきの6桁の番号）です。RGBでは赤8・緑0・青0。漆黒は、黒に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

漆黒を使うときの目安

白い文字20.8:1
黒い文字1.0:1

漆黒の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 20.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #080000;            /* 文字を漆黒にする */
background-color: #080000; /* 背景を漆黒にする */
