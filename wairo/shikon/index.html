紫紺のカラーコード

#400B36

紺を帯びた深い紫。春の選抜高校野球の優勝旗「紫紺の大旗」の色としても知られます。

紫紺（しこん）のカラーコード（色番号・カラーナンバー）は #400B36（「#」シャープつきの6桁の番号）です。RGBでは赤64・緑11・青54。紫紺は、とても暗く落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紫紺を使うときの目安

白い文字15.9:1
黒い文字1.3:1

紫紺の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 15.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #400B36;            /* 文字を紫紺にする */
background-color: #400B36; /* 背景を紫紺にする */
