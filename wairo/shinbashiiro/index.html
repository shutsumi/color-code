新橋色のカラーコード

#59B9C6

明治の終わり、東京・新橋の芸者たちの間で流行した明るい青緑。当時の新しい化学染料の色でした。

新橋色（しんばしいろ）のカラーコード（色番号・カラーナンバー）は #59B9C6（「#」シャープつきの6桁の番号）です。RGBでは赤89・緑185・青198。新橋色は、明るく落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

新橋色を使うときの目安

白い文字2.3:1
黒い文字9.2:1

新橋色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #59B9C6;            /* 文字を新橋色にする */
background-color: #59B9C6; /* 背景を新橋色にする */
