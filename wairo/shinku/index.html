真紅のカラーコード

#B1063A

まじりけのない紅。「深紅」とも書き、濃く鮮やかな赤を指します。

真紅（しんく）のカラーコード（色番号・カラーナンバー）は #B1063A（「#」シャープつきの6桁の番号）です。RGBでは赤177・緑6・青58。真紅は、暗めで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

真紅を使うときの目安

白い文字7.1:1
黒い文字3.0:1

真紅の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B1063A;            /* 文字を真紅にする */
background-color: #B1063A; /* 背景を真紅にする */
