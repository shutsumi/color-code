東雲色のカラーコード

#F19072

「東雲（しののめ）」は夜明けの東の空のこと。明け方の空を染める、やわらかな橙です。「曙色」とも呼ばれます。

東雲色（しののめいろ）のカラーコード（色番号・カラーナンバー）は #F19072（「#」シャープつきの6桁の番号）です。RGBでは赤241・緑144・青114。東雲色は、明るくはっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

東雲色を使うときの目安

白い文字2.3:1
黒い文字9.0:1

東雲色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F19072;            /* 文字を東雲色にする */
background-color: #F19072; /* 背景を東雲色にする */
