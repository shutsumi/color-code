紫苑色のカラーコード

#968ABD

秋に咲くシオンの花の色。淡い紫で、平安時代の装束にも使われました。

紫苑色（しおんいろ）のカラーコード（色番号・カラーナンバー）は #968ABD（「#」シャープつきの6桁の番号）です。RGBでは赤150・緑138・青189。紫苑色は、中くらいの明るさで落ち着いた紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

紫苑色を使うときの目安

白い文字3.1:1
黒い文字6.7:1

紫苑色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #968ABD;            /* 文字を紫苑色にする */
background-color: #968ABD; /* 背景を紫苑色にする */
