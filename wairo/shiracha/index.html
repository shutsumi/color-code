白茶のカラーコード

#DAC4A5

白茶（しらちゃ）のカラーコード（色番号・カラーナンバー）は #DAC4A5（「#」シャープつきの6桁の番号）です。RGBでは赤218・緑196・青165。白茶は、明るく落ち着いた橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

白茶を使うときの目安

白い文字1.7:1
黒い文字12.4:1

白茶の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #DAC4A5;            /* 文字を白茶にする */
background-color: #DAC4A5; /* 背景を白茶にする */
