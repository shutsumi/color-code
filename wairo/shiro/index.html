白のカラーコード

#FFFFFF

白（しろ）のカラーコード（色番号・カラーナンバー）は #FFFFFF（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑255・青255。白は、白に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

白を使うときの目安

白い文字1.0:1
黒い文字21.0:1

白の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 21.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFFFFF;            /* 文字を白にする */
background-color: #FFFFFF; /* 背景を白にする */
