猩々緋のカラーコード

#CE313D

中国の伝説の生き物・猩々の血のような赤。戦国武将の陣羽織にも使われました。

猩々緋（しょうじょうひ）のカラーコード（色番号・カラーナンバー）は #CE313D（「#」シャープつきの6桁の番号）です。RGBでは赤206・緑49・青61。猩々緋は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

猩々緋を使うときの目安

白い文字5.1:1
黒い文字4.1:1

猩々緋の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #CE313D;            /* 文字を猩々緋にする */
background-color: #CE313D; /* 背景を猩々緋にする */
