しゅいろ

朱色のカラーコード

#EF454A

天然の鉱物・辰砂からとる顔料「朱」の色。朱肉や神社の鳥居の色です。

朱色（しゅいろ）のカラーコード（色番号・カラーナンバー）は #EF454A（「#」シャープつきの6桁の番号）です。RGBでは赤239・緑69・青74。朱色は、中くらいの明るさで鮮やかな赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

朱色を使うときの目安

白い文字3.7:1
黒い文字5.6:1

朱色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #EF454A;            /* 文字を朱色にする */
background-color: #EF454A; /* 背景を朱色にする */
