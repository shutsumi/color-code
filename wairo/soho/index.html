赭のカラーコード

#AB6953

赤土（そほ）の色。昔から顔料として使われてきた、暗い赤茶です。

赭（そほ）のカラーコード（色番号・カラーナンバー）は #AB6953（「#」シャープつきの6桁の番号）です。RGBでは赤171・緑105・青83。赭は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

赭を使うときの目安

白い文字4.3:1
黒い文字4.9:1

赭の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 4.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AB6953;            /* 文字を赭にする */
background-color: #AB6953; /* 背景を赭にする */

赭の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
