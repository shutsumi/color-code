すみいろ

墨色のカラーコード

#343434

書道で使う墨の色。わずかに灰色を含んだ黒です。

墨色（すみいろ）のカラーコード（色番号・カラーナンバー）は #343434（「#」シャープつきの6桁の番号）です。RGBでは赤52・緑52・青52。墨色は、黒に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

墨色を使うときの目安

白い文字12.4:1
黒い文字1.7:1

墨色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 12.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #343434;            /* 文字を墨色にする */
background-color: #343434; /* 背景を墨色にする */

墨色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
