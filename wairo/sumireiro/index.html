すみれいろ

菫色のカラーコード

#705DA8

スミレの花の色。英語のバイオレットにあたる、青みの紫です。

菫色（すみれいろ）のカラーコード（色番号・カラーナンバー）は #705DA8（「#」シャープつきの6桁の番号）です。RGBでは赤112・緑93・青168。菫色は、暗めではっきりした紫系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

菫色を使うときの目安

白い文字5.5:1
黒い文字3.8:1

菫色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #705DA8;            /* 文字を菫色にする */
background-color: #705DA8; /* 背景を菫色にする */
