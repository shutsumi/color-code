蘇芳色のカラーコード

#973C3F

東南アジアから輸入された木・スオウの芯で染めた色。黒みを帯びた赤です。

蘇芳色（すおういろ）のカラーコード（色番号・カラーナンバー）は #973C3F（「#」シャープつきの6桁の番号）です。RGBでは赤151・緑60・青63。蘇芳色は、暗めではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

蘇芳色を使うときの目安

白い文字6.9:1
黒い文字3.0:1

蘇芳色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #973C3F;            /* 文字を蘇芳色にする */
background-color: #973C3F; /* 背景を蘇芳色にする */

蘇芳色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
