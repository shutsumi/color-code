煤竹色のカラーコード

#6F514C

囲炉裏の煙で長い年月いぶされ、すすけた竹の色です。

煤竹色（すすたけいろ）のカラーコード（色番号・カラーナンバー）は #6F514C（「#」シャープつきの6桁の番号）です。RGBでは赤111・緑81・青76。煤竹色は、暗めでくすんだ赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

煤竹色を使うときの目安

白い文字7.1:1
黒い文字3.0:1

煤竹色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6F514C;            /* 文字を煤竹色にする */
background-color: #6F514C; /* 背景を煤竹色にする */
