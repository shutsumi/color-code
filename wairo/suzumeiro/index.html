すずめいろ

雀色のカラーコード

#864337

スズメの頭の羽の色。夕暮れどきを「雀色時（すずめいろどき）」と呼びます。

雀色（すずめいろ）のカラーコード（色番号・カラーナンバー）は #864337（「#」シャープつきの6桁の番号）です。RGBでは赤134・緑67・青55。雀色は、暗めで落ち着いた赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

雀色を使うときの目安

白い文字7.3:1
黒い文字2.9:1

雀色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #864337;            /* 文字を雀色にする */
background-color: #864337; /* 背景を雀色にする */

雀色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
