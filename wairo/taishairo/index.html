たいしゃいろ

代赭色のカラーコード

#B36C3C

中国・代州で産出した赤土「代赭」の色。黄みがかった赤茶です。

代赭色（たいしゃいろ）のカラーコード（色番号・カラーナンバー）は #B36C3C（「#」シャープつきの6桁の番号）です。RGBでは赤179・緑108・青60。代赭色は、中くらいの明るさではっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

代赭色を使うときの目安

白い文字4.1:1
黒い文字5.1:1

代赭色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B36C3C;            /* 文字を代赭色にする */
background-color: #B36C3C; /* 背景を代赭色にする */

代赭色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
