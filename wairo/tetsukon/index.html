てつこん

鉄紺のカラーコード

#003149

鉄色（青緑がかった暗い色）を帯びた紺。わずかに緑みのある暗い青です。

鉄紺（てつこん）のカラーコード（色番号・カラーナンバー）は #003149（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑49・青73。鉄紺は、とても暗く落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鉄紺を使うときの目安

白い文字13.7:1
黒い文字1.5:1

鉄紺の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 13.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #003149;            /* 文字を鉄紺にする */
background-color: #003149; /* 背景を鉄紺にする */

鉄紺の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
