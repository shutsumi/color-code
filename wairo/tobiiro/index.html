とびいろ

鳶色のカラーコード

#85403A

空を舞うトビの羽の色。赤みのある茶色で、瞳の色のたとえにも使われます。

鳶色（とびいろ）のカラーコード（色番号・カラーナンバー）は #85403A（「#」シャープつきの6桁の番号）です。RGBでは赤133・緑64・青58。鳶色は、暗めで落ち着いた赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鳶色を使うときの目安

白い文字7.5:1
黒い文字2.8:1

鳶色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 7.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #85403A;            /* 文字を鳶色にする */
background-color: #85403A; /* 背景を鳶色にする */

鳶色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
