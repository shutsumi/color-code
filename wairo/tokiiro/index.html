鴇色のカラーコード

#F3A696

トキが翼を広げたときに見える、風切羽の淡い紅色。「朱鷺色」とも書きます。

鴇色（ときいろ）のカラーコード（色番号・カラーナンバー）は #F3A696（「#」シャープつきの6桁の番号）です。RGBでは赤243・緑166・青150。鴇色は、明るく落ち着いたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鴇色を使うときの目安

白い文字2.0:1
黒い文字10.7:1

鴇色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F3A696;            /* 文字を鴇色にする */
background-color: #F3A696; /* 背景を鴇色にする */
