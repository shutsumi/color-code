常磐色のカラーコード

#007B43

常磐色（ときわいろ）のカラーコード（色番号・カラーナンバー）は #007B43（「#」シャープつきの6桁の番号）です。RGBでは赤0・緑123・青67。常磐色は、中くらいの明るさではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

常磐色を使うときの目安

白い文字5.4:1
黒い文字3.9:1

常磐色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.4:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #007B43;            /* 文字を常磐色にする */
background-color: #007B43; /* 背景を常磐色にする */
