木賊色のカラーコード

#22825D

木賊色（とくさいろ）のカラーコード（色番号・カラーナンバー）は #22825D（「#」シャープつきの6桁の番号）です。RGBでは赤34・緑130・青93。木賊色は、中くらいの明るさではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

木賊色を使うときの目安

白い文字4.8:1
黒い文字4.4:1

木賊色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 4.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #22825D;            /* 文字を木賊色にする */
background-color: #22825D; /* 背景を木賊色にする */
