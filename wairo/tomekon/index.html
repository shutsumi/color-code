とめこん

留紺のカラーコード

#1C305C

これ以上は濃く染まらないところで「留めた」紺。もっとも濃い紺です。

留紺（とめこん）のカラーコード（色番号・カラーナンバー）は #1C305C（「#」シャープつきの6桁の番号）です。RGBでは赤28・緑48・青92。留紺は、とても暗く落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

留紺を使うときの目安

白い文字12.9:1
黒い文字1.6:1

留紺の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 12.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #1C305C;            /* 文字を留紺にする */
background-color: #1C305C; /* 背景を留紺にする */

留紺の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
