とりのこいろ

鳥の子色のカラーコード

#FFF1CF

鶏の卵の殻の色。和紙の「鳥の子紙」も、この色に由来します。

鳥の子色（とりのこいろ）のカラーコード（色番号・カラーナンバー）は #FFF1CF（「#」シャープつきの6桁の番号）です。RGBでは赤255・緑241・青207。鳥の子色は、とても明るく落ち着いた黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鳥の子色を使うときの目安

白い文字1.1:1
黒い文字18.7:1

鳥の子色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 18.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FFF1CF;            /* 文字を鳥の子色にする */
background-color: #FFF1CF; /* 背景を鳥の子色にする */

鳥の子色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
