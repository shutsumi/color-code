躑躅色のカラーコード

#E761A4

春に咲くツツジの花の色。紫みの鮮やかな紅です。

躑躅色（つつじいろ）のカラーコード（色番号・カラーナンバー）は #E761A4（「#」シャープつきの6桁の番号）です。RGBでは赤231・緑97・青164。躑躅色は、中くらいの明るさではっきりしたピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

同じカラーコードで載っている色：牡丹色

躑躅色を使うときの目安

白い文字3.2:1
黒い文字6.6:1

躑躅色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #E761A4;            /* 文字を躑躅色にする */
background-color: #E761A4; /* 背景を躑躅色にする */
