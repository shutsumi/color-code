露草色のカラーコード

#21A0DB

夏の朝に咲くツユクサの花の色。この花の汁は、昔は下絵を描く染料にも使われました。

露草色（つゆくさいろ）のカラーコード（色番号・カラーナンバー）は #21A0DB（「#」シャープつきの6桁の番号）です。RGBでは赤33・緑160・青219。露草色は、中くらいの明るさではっきりした青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

露草色を使うときの目安

白い文字3.0:1
黒い文字7.1:1

露草色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 7.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #21A0DB;            /* 文字を露草色にする */
background-color: #21A0DB; /* 背景を露草色にする */
