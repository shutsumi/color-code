鶯茶のカラーコード

#715C1F

ウグイスの羽のような色を、さらに茶色寄りにした色。江戸時代に流行しました。

鶯茶（うぐいすちゃ）のカラーコード（色番号・カラーナンバー）は #715C1F（「#」シャープつきの6桁の番号）です。RGBでは赤113・緑92・青31。鶯茶は、暗めではっきりした茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鶯茶を使うときの目安

白い文字6.5:1
黒い文字3.3:1

鶯茶の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 6.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #715C1F;            /* 文字を鶯茶にする */
background-color: #715C1F; /* 背景を鶯茶にする */

鶯茶の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
