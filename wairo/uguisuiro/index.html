鶯色のカラーコード

#918D40

春を告げる鳥・ウグイスの羽の色から。実際の羽は緑というより、くすんだ茶緑です。

鶯色（うぐいすいろ）のカラーコード（色番号・カラーナンバー）は #918D40（「#」シャープつきの6桁の番号）です。RGBでは赤145・緑141・青64。鶯色は、中くらいの明るさではっきりした茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鶯色を使うときの目安

白い文字3.4:1
黒い文字6.1:1

鶯色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #918D40;            /* 文字を鶯色にする */
background-color: #918D40; /* 背景を鶯色にする */
