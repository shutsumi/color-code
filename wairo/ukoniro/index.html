うこんいろ

鬱金色のカラーコード

#FABF14

ショウガの仲間・ウコンの根で染めた鮮やかな黄色。カレーの黄色もウコンによるものです。

鬱金色（うこんいろ）のカラーコード（色番号・カラーナンバー）は #FABF14（「#」シャープつきの6桁の番号）です。RGBでは赤250・緑191・青20。鬱金色は、明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

鬱金色を使うときの目安

白い文字1.7:1
黒い文字12.5:1

鬱金色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FABF14;            /* 文字を鬱金色にする */
background-color: #FABF14; /* 背景を鬱金色にする */
