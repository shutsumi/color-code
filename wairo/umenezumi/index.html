梅鼠のカラーコード

#AD7984

紅梅の花のような赤みを含んだ鼠色。江戸時代の粋な色の一つです。

梅鼠（うめねずみ）のカラーコード（色番号・カラーナンバー）は #AD7984（「#」シャープつきの6桁の番号）です。RGBでは赤173・緑121・青132。梅鼠は、中くらいの明るさで落ち着いた赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

梅鼠を使うときの目安

白い文字3.6:1
黒い文字5.8:1

梅鼠の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 5.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #AD7984;            /* 文字を梅鼠にする */
background-color: #AD7984; /* 背景を梅鼠にする */
