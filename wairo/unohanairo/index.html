卯の花色のカラーコード

#FBFBF6

初夏に咲くウツギの白い花「卯の花」の色。旧暦四月の「卯月」もこの花に由来します。

卯の花色（うのはないろ）のカラーコード（色番号・カラーナンバー）は #FBFBF6（「#」シャープつきの6桁の番号）です。RGBでは赤251・緑251・青246。卯の花色は、白に近い白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

卯の花色を使うときの目安

白い文字1.0:1
黒い文字20.2:1

卯の花色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 20.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #FBFBF6;            /* 文字を卯の花色にする */
background-color: #FBFBF6; /* 背景を卯の花色にする */

卯の花色の薄い色・濃い色
