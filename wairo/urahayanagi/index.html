裏葉柳のカラーコード

#C1D8AC

風にひるがえった柳の葉の裏側の色。表よりも白っぽい、淡い緑です。

裏葉柳（うらはやなぎ）のカラーコード（色番号・カラーナンバー）は #C1D8AC（「#」シャープつきの6桁の番号）です。RGBでは赤193・緑216・青172。裏葉柳は、明るく落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

裏葉柳を使うときの目安

白い文字1.5:1
黒い文字13.7:1

裏葉柳の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 13.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C1D8AC;            /* 文字を裏葉柳にする */
background-color: #C1D8AC; /* 背景を裏葉柳にする */
