うすいろ

薄色のカラーコード

#CEB4B9

平安時代に「薄色」といえば薄い紫のこと。紫が高貴な色だったため、色名を省いて呼ばれました。

薄色（うすいろ）のカラーコード（色番号・カラーナンバー）は #CEB4B9（「#」シャープつきの6桁の番号）です。RGBでは赤206・緑180・青185。薄色は、明るくくすんだピンク系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

薄色を使うときの目安

白い文字1.9:1
黒い文字10.9:1

薄色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #CEB4B9;            /* 文字を薄色にする */
background-color: #CEB4B9; /* 背景を薄色にする */

薄色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
