淡香のカラーコード

#F3BF88

淡香（うすこう）のカラーコード（色番号・カラーナンバー）は #F3BF88（「#」シャープつきの6桁の番号）です。RGBでは赤243・緑191・青136。淡香は、明るくはっきりした橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

淡香を使うときの目安

白い文字1.7:1
黒い文字12.6:1

淡香の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 12.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F3BF88;            /* 文字を淡香にする */
background-color: #F3BF88; /* 背景を淡香にする */
