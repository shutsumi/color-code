薄紅のカラーコード

#B15C65

紅花で淡く染めた紅。やさしい桃色がかった赤です。

薄紅（うすくれない）のカラーコード（色番号・カラーナンバー）は #B15C65（「#」シャープつきの6桁の番号）です。RGBでは赤177・緑92・青101。薄紅は、中くらいの明るさではっきりした赤系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

薄紅を使うときの目安

白い文字4.6:1
黒い文字4.6:1

薄紅の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 4.6:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #B15C65;            /* 文字を薄紅にする */
background-color: #B15C65; /* 背景を薄紅にする */
