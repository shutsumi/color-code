薄水色のカラーコード

#BCE1DF

薄水色（うすみずいろ）のカラーコード（色番号・カラーナンバー）は #BCE1DF（「#」シャープつきの6桁の番号）です。RGBでは赤188・緑225・青223。薄水色は、とても明るくくすんだ青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

薄水色を使うときの目安

白い文字1.4:1
黒い文字15.0:1

薄水色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 15.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #BCE1DF;            /* 文字を薄水色にする */
background-color: #BCE1DF; /* 背景を薄水色にする */
