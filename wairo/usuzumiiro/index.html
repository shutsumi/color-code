うすずみいろ

薄墨色のカラーコード

#A3A3A2

墨を水で薄めたような灰色。弔事の手紙や香典袋を薄墨で書く習わしがあります。

薄墨色（うすずみいろ）のカラーコード（色番号・カラーナンバー）は #A3A3A2（「#」シャープつきの6桁の番号）です。RGBでは赤163・緑163・青162。薄墨色は、明るい灰色の白・灰・黒系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

薄墨色を使うときの目安

白い文字2.5:1
黒い文字8.3:1

薄墨色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 8.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A3A3A2;            /* 文字を薄墨色にする */
background-color: #A3A3A2; /* 背景を薄墨色にする */

薄墨色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
