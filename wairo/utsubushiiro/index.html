空五倍子色のカラーコード

#9D896C

ヌルデの木にできる虫こぶ「五倍子（ふし）」で染めた色。中が空洞なので「うつぶし」と呼ばれます。

空五倍子色（うつぶしいろ）のカラーコード（色番号・カラーナンバー）は #9D896C（「#」シャープつきの6桁の番号）です。RGBでは赤157・緑137・青108。空五倍子色は、中くらいの明るさで落ち着いた茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

空五倍子色を使うときの目安

白い文字3.4:1
黒い文字6.2:1

空五倍子色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 6.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #9D896C;            /* 文字を空五倍子色にする */
background-color: #9D896C; /* 背景を空五倍子色にする */
