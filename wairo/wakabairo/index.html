若葉色のカラーコード

#A4CA68

初夏の若葉の色。やわらかな黄緑です。

若葉色（わかばいろ）のカラーコード（色番号・カラーナンバー）は #A4CA68（「#」シャープつきの6桁の番号）です。RGBでは赤164・緑202・青104。若葉色は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

若葉色を使うときの目安

白い文字1.9:1
黒い文字11.2:1

若葉色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A4CA68;            /* 文字を若葉色にする */
background-color: #A4CA68; /* 背景を若葉色にする */

若葉色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
