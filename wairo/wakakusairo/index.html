若草色のカラーコード

#ABC900

春に萌え出た若い草の色。あざやかな黄緑です。

若草色（わかくさいろ）のカラーコード（色番号・カラーナンバー）は #ABC900（「#」シャープつきの6桁の番号）です。RGBでは赤171・緑201・青0。若草色は、明るく鮮やかな緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

若草色を使うときの目安

白い文字1.9:1
黒い文字11.1:1

若草色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #ABC900;            /* 文字を若草色にする */
background-color: #ABC900; /* 背景を若草色にする */

若草色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
