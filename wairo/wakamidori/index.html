わかみどり

若緑のカラーコード

#A5CD89

松の若葉の色。明るく浅い緑です。

若緑（わかみどり）のカラーコード（色番号・カラーナンバー）は #A5CD89（「#」シャープつきの6桁の番号）です。RGBでは赤165・緑205・青137。若緑は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

若緑を使うときの目安

白い文字1.8:1
黒い文字11.7:1

若緑の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.7:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A5CD89;            /* 文字を若緑にする */
background-color: #A5CD89; /* 背景を若緑にする */

若緑の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
