若苗色のカラーコード

#C7DC68

田植えのころの若い稲の苗の色。明るい黄緑です。

若苗色（わかなえいろ）のカラーコード（色番号・カラーナンバー）は #C7DC68（「#」シャープつきの6桁の番号）です。RGBでは赤199・緑220・青104。若苗色は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

若苗色を使うときの目安

白い文字1.5:1
黒い文字13.9:1

若苗色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 13.9:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #C7DC68;            /* 文字を若苗色にする */
background-color: #C7DC68; /* 背景を若苗色にする */

若苗色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
