若菜色のカラーコード

#CCDE68

春の七草のように、早春に摘む若菜の色。淡い緑です。

若菜色（わかないろ）のカラーコード（色番号・カラーナンバー）は #CCDE68（「#」シャープつきの6桁の番号）です。RGBでは赤204・緑222・青104。若菜色は、とても明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

若菜色を使うときの目安

白い文字1.5:1
黒い文字14.2:1

若菜色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 14.2:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #CCDE68;            /* 文字を若菜色にする */
background-color: #CCDE68; /* 背景を若菜色にする */
