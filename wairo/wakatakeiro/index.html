若竹色のカラーコード

#7CC28E

その年に伸びた若い竹の色。緑寄りの明るい色です。

若竹色（わかたけいろ）のカラーコード（色番号・カラーナンバー）は #7CC28E（「#」シャープつきの6桁の番号）です。RGBでは赤124・緑194・青142。若竹色は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

若竹色を使うときの目安

白い文字2.1:1
黒い文字10.0:1

若竹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.0:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #7CC28E;            /* 文字を若竹色にする */
background-color: #7CC28E; /* 背景を若竹色にする */
