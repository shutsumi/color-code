わさびいろ

山葵色のカラーコード

#8EC298

すりおろしたワサビの色。薄い黄緑です。

山葵色（わさびいろ）のカラーコード（色番号・カラーナンバー）は #8EC298（「#」シャープつきの6桁の番号）です。RGBでは赤142・緑194・青152。山葵色は、明るく落ち着いた緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

山葵色を使うときの目安

白い文字2.0:1
黒い文字10.3:1

山葵色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 10.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #8EC298;            /* 文字を山葵色にする */
background-color: #8EC298; /* 背景を山葵色にする */

山葵色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
