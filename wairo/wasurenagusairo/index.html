勿忘草色のカラーコード

#9CC5E6

勿忘草色（わすれなぐさいろ）のカラーコード（色番号・カラーナンバー）は #9CC5E6（「#」シャープつきの6桁の番号）です。RGBでは赤156・緑197・青230。勿忘草色は、明るく落ち着いた青系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

勿忘草色を使うときの目安

白い文字1.8:1
黒い文字11.5:1

勿忘草色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #9CC5E6;            /* 文字を勿忘草色にする */
background-color: #9CC5E6; /* 背景を勿忘草色にする */
