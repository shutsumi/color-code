やまぶきいろ

山吹色のカラーコード

#F8B400

春に咲くヤマブキの花の色。黄金に似ていることから、時代劇では小判を「山吹色」と呼びます。

山吹色（やまぶきいろ）のカラーコード（色番号・カラーナンバー）は #F8B400（「#」シャープつきの6桁の番号）です。RGBでは赤248・緑180・青0。山吹色は、明るく鮮やかな黄系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

山吹色を使うときの目安

白い文字1.8:1
黒い文字11.5:1

山吹色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #F8B400;            /* 文字を山吹色にする */
background-color: #F8B400; /* 背景を山吹色にする */

山吹色の薄い色・濃い色
