柳色のカラーコード

#A8C97F

柳色（やなぎいろ）のカラーコード（色番号・カラーナンバー）は #A8C97F（「#」シャープつきの6桁の番号）です。RGBでは赤168・緑201・青127。柳色は、明るくはっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

柳色を使うときの目安

白い文字1.9:1
黒い文字11.3:1

柳色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 11.3:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #A8C97F;            /* 文字を柳色にする */
background-color: #A8C97F; /* 背景を柳色にする */
