蓬色のカラーコード

#616B07

草餅に使うヨモギの葉の色。やや青みのある緑です。

蓬色（よもぎいろ）のカラーコード（色番号・カラーナンバー）は #616B07（「#」シャープつきの6桁の番号）です。RGBでは赤97・緑107・青7。蓬色は、暗めではっきりした緑系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

蓬色を使うときの目安

白い文字5.8:1
黒い文字3.6:1

蓬色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 5.8:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #616B07;            /* 文字を蓬色にする */
background-color: #616B07; /* 背景を蓬色にする */
