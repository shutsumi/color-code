羊羹色のカラーコード

#6D3C14

和菓子の羊羹の色。黒い着物が色あせて赤茶けた様子も「羊羹色」と言いました。

羊羹色（ようかんいろ）のカラーコード（色番号・カラーナンバー）は #6D3C14（「#」シャープつきの6桁の番号）です。RGBでは赤109・緑60・青20。羊羹色は、暗めではっきりした茶系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

羊羹色を使うときの目安

白い文字9.1:1
黒い文字2.3:1

羊羹色の上に文字をのせるなら、白い文字のほうが読みやすくなります（コントラスト比 9.1:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #6D3C14;            /* 文字を羊羹色にする */
background-color: #6D3C14; /* 背景を羊羹色にする */

羊羹色の薄い色・濃い色

白や黒を混ぜた色です。クリックでカラーコードをコピーできます。
