雄黄色のカラーコード

#EE9D19

鉱物・雄黄（硫化ヒ素）の色。明るく鮮やかな黄色で、昔は顔料に使われました。

雄黄色（ゆうおういろ）のカラーコード（色番号・カラーナンバー）は #EE9D19（「#」シャープつきの6桁の番号）です。RGBでは赤238・緑157・青25。雄黄色は、明るく鮮やかな橙・オレンジ系の色です。

クリックするとコピーされます。CanvaやPowerPointには「#なし」、HTMLやCSSには「#つき」が便利です。

雄黄色を使うときの目安

白い文字2.2:1
黒い文字9.5:1

雄黄色の上に文字をのせるなら、黒い文字のほうが読みやすくなります（コントラスト比 9.5:1）。Webの読みやすさの目安（4.5:1）を満たしているので、本文の文字にも使えます。

HTML・CSSでの書き方

color: #EE9D19;            /* 文字を雄黄色にする */
background-color: #EE9D19; /* 背景を雄黄色にする */
